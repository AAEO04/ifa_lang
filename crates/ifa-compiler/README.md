# Ifá Compiler (ifa-compiler)

The **Ifá Compiler** is the transformation engine that converts Abstract Syntax Trees (AST) into executable Ifá Bytecode (`.ifab`). It serves as the primary "Forge" of the language, preparing the instructions that the **ifa-vm** will eventually execute.

## Core Responsibilities

- **AST to Bytecode Mapping**: Translates high-level Ifá constructs into a stable, compact binary format.
- **Incremental Compilation**: Optimized to re-compile only the modules or lines that have changed.
- **REPL-Speed Generation**: Supports an "Interactive Mode" that emits bytecode directly to an in-memory buffer for the REPL.
- **Source Map Attachment**: Generates rich metadata (Spans) for every instruction, enabling the **Iroke Mirror** debugging experience.

## Key Features

### 1. Unified Compilation Pipeline
The compiler handles multiple build targets through a single, consistent pipeline:
*   **Script Mode**: Compiles a single `.ifa` file into a transient bytecode block.
*   **Bundle Mode**: Bundles an entire project (via `ifa.toml`) into a single, portable `.ifab` binary.
*   **REPL Mode**: Hot-compiles single statements into a "Warm" VM session.

### 2. Constant Evaluation Integration
The compiler works hand-in-hand with **ifa-babalawo**. Before generating opcodes, it asks Babalawo to "Consult the Nuts" (Constant Folding). 
*   If an expression like `10 * 5` is found, the compiler emits a single `PushInt(50)` instead of three separate instructions.

### 3. Zero-Copy Interning
Utilizing the type system in **ifa-types**, the compiler interns every string and identifier encountered. This ensures that the generated bytecode is as small as possible and that the VM never has to perform redundant string allocations.

### 4. Interactive Mode
In interactive mode (used by the CLI REPL), the compiler maintains a "Symbol Table" of the current session. When the user types a new line, the compiler generates a bytecode "Fragment" that is ready to be injected directly into the running VM's instruction tape.

## Usage

### In Rust
```rust
use ifa_compiler::Compiler;
use ifa_types::ast::Program;

let compiler = Compiler::new();
let bytecode = compiler.compile(&program)?;

// Save to file
bytecode.save("output.ifab")?;
```

### Via CLI
```bash
ifa compile path/to/project --output build/
```

## Performance Note
The compiler is designed to scale with your hardware. It uses the **ifa-infra** parallelism primitives to compile multiple modules simultaneously, ensuring that even large-scale projects build in milliseconds.
