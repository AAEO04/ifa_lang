Reserved Words

Bilingual Keywords and Language Primitives

Overview

Ifá-Lang supports bilingual keywords with both Yoruba and English variants. All reserved words have cultural significance and reflect Yoruba philosophical concepts while maintaining accessibility for English speakers.

This list is source-verified against crates/ifa-parser/src/grammar.pest. Every keyword shown is parsed by the actual compiler.

Variable and Function Declarations

ayanmo / let / var / variable

Meaning: Destiny / to have

Usage: Variable declaration

ayanmo x = 5;
let name = "Alice";

const / loruko / ka / ayanfe

Meaning: Constant / name / beloved

Usage: Constant declaration

const PI = 3.14159;
loruko VERSION = "1.3.0";

ese / fn / function / def

Meaning: Verse / function

Usage: Function definition

ese greet(name) { ... }
fn calculate(x, y) { ... }

odu / class

Meaning: Odù (sacred pattern) / class

Usage: Type/structure definition

odu Person { ... }
class Database { ... }

gbangba / public / fi / export

Meaning: Openly / public

Usage: Visibility modifier on declarations

gbangba ese main() { ... }
public let API_KEY = "secret";

daro / async

Meaning: Wait / asynchronous

Usage: Async function modifier

daro ese fetch_data() { ... }
async fn process() { ... }

Control Flow

ti / bi / if

Meaning: If / conditional

Usage: Conditional statement

ti x > 0 { ... }
if condition { ... }

bibeko / else

Meaning: Otherwise / else

Usage: Else clause (supports else-if chaining)

ti x > 0 { ... } bibeko { ... }
if condition { ... } else { ... }

nigba / while

Meaning: During / while

Usage: While loop

nigba x < 10 { ... }
while condition { ... }

fun / for

Meaning: To do / for each

Usage: For loop

fun i ninu items { ... }
for item in collection { ... }

ninu / in

Meaning: Inside / in

Usage: For loop iterator

fun i ninu 0..10 { ... }
for i in range { ... }

yan / match

Meaning: To choose / match

Usage: Pattern matching statement

yan (value) {
    0 => Irosu.fo("zero"),
    _ => Irosu.fo("other")
}
match (value) {
    1 => "one",
    _ => "other"
}

da / break

Meaning: To stop / break

Usage: Break from loop

da;
break;

tesiwaju / bayan / continue

Meaning: To continue / continue

Usage: Continue to next loop iteration

tesiwaju;
continue;

pada / return

Meaning: To return / come back

Usage: Return from function

pada result;
return value;

Error Handling

gbiyanju / try

Meaning: To attempt / try

Usage: Try block

gbiyanju { ... } gba (e) { ... }
try { ... } catch (e) { ... }

gba / catch

Meaning: To receive / catch

Usage: Catch block

gbiyanju { ... } gba (error) { ... }
try { ... } catch (error) { ... }

nipari / finally

Meaning: In conclusion / finally

Usage: Finally block

gbiyanju { ... } nipari { ... }
try { ... } finally { ... }

ewo / assert / verify

Meaning: Prohibition / assertion

Usage: Assertion statement

ewo x >= 0;
assert condition;
verify balance >= 0;

Imports and Modules

iba / import / mu

Meaning: To borrow / import / take

Usage: Import statement

iba std.irose;
import std.utils;

lati / from

Meaning: From / source

Usage: Named import clause

iba { fo, ka } lati std.irose;
import { print, read } from std.irose;

Memory and Resources

opon / mem

Meaning: Divination tray / memory

Usage: Memory configuration directive

opon: kekere;
mem: nla;

ebo / sacrifice

Meaning: Offering / sacrifice

Usage: Resource acquisition / epoch region

ebo "config.json";
ebo "scope" { ... }

defer / gbe

Meaning: Keep / defer

Usage: Deferred cleanup at scope exit

defer { close(file); }
gbe { free(buffer); }

ailewu / unsafe

Meaning: Without danger / unsafe (ironic)

Usage: Unsafe code block

ailewu { ... }
unsafe { ... }

Async and Await

reti / await

Meaning: To wait / await

Usage: Await an async expression

reti fetch_data();

Usage Guidelines

Bilingual Support

  • Mixed Usage: Can mix Yoruba and English in same program
  • Consistency: Choose one style per project for consistency
  • Cultural Context: Yoruba keywords preserve cultural meaning
  • Accessibility: English keywords provide accessibility

Best Practices

  • Domain Names: Use Odu domains without imports
  • Type Names: Use type hints for clarity
  • Constants: Use const/loruko for immutable values
  • Error Handling: Use gbiyanju/gba for robust error handling
  • Cleanup: Use defer/gbe for guaranteed scope cleanup

Reserved Word Restrictions

  • No Shadowing: Cannot shadow reserved words
  • No Redefinition: Cannot redefine reserved words
  • Context Sensitive: Some words are context-sensitive (e.g., public)
