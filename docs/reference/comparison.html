Ifa-Lang vs Others

Language Comparison and Feature Analysis

Overview

Ifa-Lang is a dynamic language with a domain-based standard library (16 Odu domains), bilingual keywords (Yoruba/English), and an Opon-based memory system. It compiles to bytecode for the IfaVM or can be transpiled to Rust for native binaries.

IfaValue Type System

  • 32-byte tagged union enum
  • Primitives inlined: Null, Bool, Int(i64), Float(f64)
  • CompactString with SSO (21 bytes inline, else Arc<str>)
  • Heap types via Arc: List, Map, Fn, Resource
  • VM-specific: AstFn, Closure, Future, Actor, Result, Break, Continue

Memory Details

  • IfaValue is 32 bytes (test-verified)
  • CompactString SSO: strings up to 21 bytes stored inline
  • Strings longer than 21 bytes: Arc<str> (heap, ref-counted)
  • Opon sizes: Kekere (256), Arinrin (4096), Nla (65536), Ailopin (1M ceiling)
  • Ebo epochs provide scoped allocation release
  • No generational GC, no mark-and-sweep

IfaError Variants

  • Math: DivisionByZero, Overflow, Underflow
  • Type: ArityMismatch, ArgumentError, TypeError, ConversionError
  • Index: IndexOutOfBounds, KeyNotFound
  • I/O: FileNotFound, PermissionDenied, IoError
  • Network: ConnectionFailed, Timeout, SsrfBlocked
  • VM: StackOverflow, StackUnderflow, UndefinedVariable, OponExhausted
  • Generic: AssertionFailed, NotImplemented, Custom, UserError
  • Parser: Parse, Compile, Runtime

Built-in Domain Access

// 16 Odu domains are built-in
Irosu.fo("Hello, World!");

# Standard library imports required
import math
import datetime

now = datetime.datetime.now()

Performance Characteristics

Language Execution Speed Memory Usage Startup Time Concurrency
Ifa-Lang Fast (bytecode VM or transpiled to Rust) Moderate (Arc ref-counting) Fast Osa domain + actors
TypeScript Medium (JS runtime) High (JS runtime) Fast (JIT) Event loop + workers
Python Slow (interpreted) High (GC overhead) Medium (import time) GIL + threading
Rust Very Fast (native) Low (no GC) Fast (compiled) Async + channels

Ifa-Lang Performance Features

  • Bytecode VM with direct-threaded dispatch
  • CompactString SSO (0 alloc for strings up to 21 bytes)
  • Small int pool (0-255 cached)
  • Arc sharing for List/Map/Fn (copy-on-write ref-counting)
  • Optional transpilation to Rust for native performance

Migration Paths

From JavaScript/TypeScript

  • Replace console.log with Irosu.fo()
  • Replace Array methods with Ogunda domain
  • Replace Math object with Obara/Oturupon domains
  • Replace arrow functions with { args -> expr } closures

From Python

  • Replace print()/input() with Irosu domain
  • Replace math, random, datetime with domains
  • Replace file I/O with Odi domain
  • Replace try/except with gbiyanju/gba

From Rust

  • Dynamic typing vs static type system
  • Arc ref-counting vs borrow checker
  • Runtime errors vs compile-time guarantees
  • Opon memory store vs ownership model
