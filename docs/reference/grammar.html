Grammar Reference

Complete Language Grammar Specification

Overview

Ifá-Lang uses a Pest PEG grammar definition for parsing. The grammar supports bilingual keywords (Yoruba and English) and implements the full language specification including the 16 Odu domains, expression precedence, and special constructs.

Program Structure

Top-Level Structure

Program Grammar 
program = { SOI ~ statement* ~ EOI }

Statements

Statement List (in parsing order)

Statement Grammar 
statement = {
    import_stmt
    | from_import_stmt
    | abo_stmt                   // Strict mode
    | ase_stmt                   // End marker
    | opon_stmt                  // Memory directive
    | ebo_stmt                   // Offering / epoch region
    | defer_stmt                 // Deferred cleanup
    | ailewu_stmt                // Unsafe block
    | var_decl                   // Variable declaration
    | const_stmt                 // Constant declaration
    | alias_stmt                 // Alias / rename
    | update_stmt                // +=, -=, *=, /=, %=
    | assignment_stmt            // =
    | iwa_def                    // Protocol / interface definition
    | odu_def                    // Class / struct definition
    | ese_def                    // Function definition
    | if_stmt                    // Conditional
    | while_stmt                 // While loop
    | for_stmt                   // For loop
    | return_stmt                // Return
    | break_stmt                 // Break
    | continue_stmt              // Continue
    | throw_stmt                 // Throw / ta
    | taboo_stmt                 // Domain taboo
    | ewo_stmt                   // Assertion
    | assert_type_stmt           // Runtime type assertion
    | match_stmt                 // Pattern matching
    | try_stmt                   // Try/catch/finally
    | yield_stmt                 // Yield control
    | instruction                // odu_call, method_call, function_call
    | COMMENT
}

Imports

Import Grammar 
import_stmt = { import_kw ~ module_path ~ ";" }
from_import_stmt = { import_kw ~ "{" ~ ident ~ ("," ~ ident)* ~ "}" ~ from_kw ~ module_path ~ ";" }
module_path = { ident ~ ("." ~ ident)* }

import_kw = { "iba" | "ìbà" | "import" | "mu" }
from_kw = { "lati" | "láti" | "from" }

Variable Declarations

Variable Grammar 
var_decl = { public_mod? ~ var_kw ~ ident ~ type_hint? ~ "=" ~ expression ~ ";" }
type_hint = { ":" ~ type_name }

var_kw = { "ayanmo" | "ayanmọ" | "àyànmọ́" | "variable" | "let" | "var" }

Constants

Constant Grammar 
const_stmt = { public_mod? ~ const_kw ~ ident ~ "=" ~ expression ~ ";" }

const_kw = { "const" | "loruko" | "ka" | "ayanfe" | "àyànfẹ́" }

Assignment and Update

Assignment Grammar 
assignment_stmt = { lvalue ~ "=" ~ expression ~ ";" }
update_stmt = { lvalue ~ update_op ~ expression ~ ";" }

lvalue = { deref_lvalue | index_lvalue | property_access | ident }
deref_lvalue = { "*" ~ expression }
index_lvalue = { ident ~ "?."? ~ "[" ~ expression ~ "]" }

update_op = { "+="  | "-=" | "*=" | "/=" | "%=" }

// Examples:
x = 10;
x += 5;
*p = 20;
arr[0] = 30;

Functions and Classes

Function Definitions

Function Grammar 
ese_def = { public_mod? ~ async_mod? ~ ese_kw ~ ident ~ "(" ~ params? ~ ")" ~ "{" ~ statement* ~ "}" }
params = { param ~ ("," ~ param)* }
param = { ident ~ (":" ~ type_name)? }

ese_kw = { "ese" | "ẹsẹ" | "fn" | "function" | "def" }
async_mod = { async_kw }
async_kw = { "daro" | "async" }
public_mod = { "gbangba" | "public" | "fi" | "export" }

Odu Definitions (Classes)

Odu Grammar 
odu_def = { public_mod? ~ odu_kw ~ ident ~ "{" ~ odu_body ~ "}" }
odu_body = { (ese_def | var_decl)* }

odu_kw = { "odu" | "odù" | "class" }

Control Flow

If / Else If / Else

If Grammar 
if_stmt = { if_kw ~ expression ~ "{" ~ statement* ~ "}" ~ else_clause? }

else_clause = {
    else_kw ~ if_kw ~ expression ~ "{" ~ statement* ~ "}" ~ else_clause?  // else if
    | else_kw ~ "{" ~ statement* ~ "}"                                      // else
}

if_kw = { "ti" | "bí" | "if" }
else_kw = { "bibẹkọ" | "else" }

While Grammar 
while_stmt = { while_kw ~ expression ~ "{" ~ statement* ~ "}" }
while_kw = { "nigba" | "while" }

For Loop

For Grammar

Loop Control Grammar

Return

Return Grammar

Match

Match Grammar 
match_stmt = { match_kw ~ "(" ~ expression ~ ")" ~ "{" ~ match_arm* ~ "}" }

match_arm = { match_pattern ~ "=>" ~ (statement | ("{" ~ statement* ~ "}")) }
match_pattern = { range_pattern | literal_pattern | wildcard_pattern }
range_pattern = { expression ~ ".." ~ expression }
literal_pattern = { expression }
wildcard_pattern = { "_" }

match_kw = { "yàn" | "yán" | "match" }

nipari_clause = { nipari_kw ~ "{" ~ statement* ~ "}" }

try_kw = { "gbiyanju" | "gbìyànjú" | "try" }

Ebo (Offering / Epoch Region)

Ebo Grammar 
ebo_stmt = { ebo_kw ~ expression ~ ("{" ~ statement* ~ "}")? ~ ";"? }

ebo_kw = { "ebo" | "ẹbọ" | "sacrifice" }

// With body: creates a scoped memory epoch
// Without body: single-statement resource offering
// Examples:

Expressions (Precedence, Low to High)

Precedence Chain (Low to High)

expression       = { pipeline_expr }                                   // Lowest precedence
pipeline_expr    = { null_coalesce_expr ~ ("|>" ~ null_coalesce_expr)* }
null_coalesce_expr = { or_expr ~ (null_coalesce_op ~ or_expr)* }
or_expr          = { and_expr ~ (or_op ~ and_expr)* }
and_expr         = { not_expr ~ (and_op ~ not_expr)* }
not_expr         = { comparison }
comparison       = { arith_expr ~ (comp_op ~ arith_expr)* }
arith_expr       = { term ~ ((add_op | sub_op) ~ term)* }
term             = { pow_expr ~ ((mul_op | div_op | mod_op) ~ pow_expr)* }
pow_expr         = { factor ~ (pow_op ~ factor)* }                      // ** exponentiation
factor           = { unary_op* ~ atom ~ try_op? }                       // Highest (tight) binding

Pipeline Operator

The pipeline operator |> threads the left operand as the first argument of the right operand, enabling left-to-right function composition:

Pipeline Grammar 
pipeline_expr = { null_coalesce_expr ~ ("|>" ~ null_coalesce_expr)* }

// Examples:
result = items |> Ogunda.map(fn(x) { x * 2 }) |> Ogunda.filter(fn(x) { x > 10 });
// Equivalent to: Ogunda.filter(Ogunda.map(items, fn(x) { x * 2 }), fn(x) { x > 10 })

Operators

// Arithmetic
add_op = { "+" }
sub_op = { "-" }
mul_op = { "*" }
div_op = { "/" }
mod_op = { "%" }

// Comparison
comp_op = { "==" | "!=" | "<=" | ">=" | "<" | ">" }

// Logical
and_op = { "&&" | "ati" | "and" }
or_op = { "||" | "tabi" | "or" }
not_op = { "!" | "kii" | "not" }

// Other
null_coalesce_op = { "??" }
pow_op = { "**" }
unary_op = { "+" | "-" | "&" | "*" }
chain_op = { "." | "?." }
try_op = { "?" }

Atom (Expression Base)

atom = {
    lambda_expr                    // ese(x) { x * 2 }
    | odu_call                     // Obara.fikun(10)
    | method_call                  // obj.method(args)
    | property_access              // obj.field
    | function_call                // func(args)
    | index_access                 // arr[0] or arr?.[0]
    | await_expr                   // reti expr
    | move_expr                    // yanda expr (ownership transfer)
    | list_literal                 // [1, 2, 3]
    | map_literal                  // { "key": value }
    | set_literal                  // Set { 1, 2, 3 }
    | number                       // 42, 3.14, 0xFF, 0b101
    | interpolated_string          // $"Hello {name}"
    | string                       // "text" or 'text'
    | boolean                      // true, false, otito, iro
    | nil                          // null, nil, ofo
    | ident                        // variable name
    | "(" ~ expression ~ ")"       // grouping
}

Literals

// Number (integer, float, hex, binary)
number = {
    ("0x" ~ (ASCII_HEX_DIGIT | "_")+)      // Hex
    | ("0b" ~ (ASCII_BIN_DIGIT | "_")+)     // Binary
    | (ASCII_DIGIT ~ (ASCII_DIGIT | "_")*   // Decimal/float
        ~ ("." ~ ASCII_DIGIT ~ (ASCII_DIGIT | "_")*)?)
}

// String (double or single quotes)
string = {
    "\"" ~ ( (!("\"" | "\\") ~ ANY) | ("\\" ~ ANY) )* ~ "\""
    | "'" ~ ( (!("'" | "\\") ~ ANY) | ("\\" ~ ANY) )* ~ "'"
}

// Set literal: Set { 1, 2, 3 }
set_literal = { set_kw ~ "{" ~ (expression ~ ("," ~ expression)*)? ~ "}" }
set_kw = { "Set" | "set" }

// Sets are unordered collections of unique values:
// ayanmo colors = Set { "red", "green", "blue" };

// Interpolated string: $"Hello {name}"
interpolated_string = { "$" ~ "\"" ~ (interp_part)* ~ "\"" }
interp_text = { "\"" | "{" | "\\" ... }
interp_expr = { "{" ~ expression ~ "}" }

// Booleans
boolean = { "true" | "false" | "otito" | "iro" }

// Null
nil = { "ofo" | "null" | "nil" }

Lambda Expression

lambda_expr = { ese_kw ~ "(" ~ params? ~ ")" ~ "{" ~ statement* ~ "}" }

// Example: ese(x, y) { pada x + y; }
// Equivalent to: fn(x, y) { return x + y; }

Move Expression

move_expr = { move_kw ~ expression }

move_kw = { "yanda" | "free" }

// Transfers ownership of a value. After the move, the original
// binding is invalidated and cannot be used.
// Example: yanda large_data to worker;

Calls and Property Access

// Domain call: Obara.fikun(10)
odu_call = { odu_name ~ chain_op ~ ident ~ "(" ~ arguments? ~ ")" }

// Method call: obj.method(args) or obj?.method(args)
method_call = { ident ~ chain_op ~ ident ~ "(" ~ arguments? ~ ")" }

// Function call: func(args)
function_call = { ident ~ "(" ~ arguments? ~ ")" }

// Property access: obj.field or obj?.field
property_access = { ident ~ ( chain_op ~ ident )+ }

// Index: arr[0] or arr?.[0]
index_access = { ident ~ "?."? ~ "[" ~ expression ~ "]" }

// Arguments
arguments = { expression ~ ("," ~ expression)* }

Lists and Maps

// List: [1, 2, 3] or []
list_literal = { "[" ~ (expression ~ ("," ~ expression)*)? ~ "]" }

// Map: { "key": value }
map_literal = { "{" ~ (map_entry ~ ("," ~ map_entry)*)? ~ "}" }
map_entry = { (string | ident) ~ ":" ~ expression }

Comments

Comment Syntax

COMMENT = {
    block_comment       // /* ... */
    | doc_comment       // /// ...
    | line_comment_slash  // ...
    | line_comment_hash   // # ...
}

doc_comment = { "///" ~ (!NEWLINE ~ ANY)* }
block_comment = { "/*" ~ (!"*/" ~ ANY)* ~ "*/" }
line_comment_slash = { "//" ~ (!NEWLINE ~ ANY)* }
line_comment_hash = { "#" ~ (!NEWLINE ~ ANY)* }

Terminals and Whitespace

Identifier and Whitespace Rules

// Identifiers: Unicode-aware (supports Yoruba characters)
ident = { (ASCII_ALPHA | "_" | '\u{0080}'..'\u{FFFF}')
    ~ (ASCII_ALPHANUMERIC | "_" | '\u{0080}'..'\u{FFFF}')* }

// Whitespace (automatically skipped)
WHITESPACE = { " " | "\t" | "\r" | "\n" }
