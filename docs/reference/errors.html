errors.ifa

Error Reference

IfaError System with Cultural Wisdom

Overview

Ifa-Lang uses a unified error system through IfaError (defined in crates/ifa-types/src/error.rs). Every runtime component re-exports this single error type. Errors include Yoruba proverbs and structured error codes from ifa-bytecode's ErrorCode enum.

Error Categories

Math Errors (Obara / Oturupon) - ErrorCode 0x03XX

DivisionByZero

Proverb: "Bi a ba pin ohun ti ko si, a o le ri nnkan."

Code: DivByZero

// Causes error
ayanmo result = 10 / 0;

Overflow

Message: "Numeric overflow: {0}"

Code: Overflow

// i64 overflow promotes to Float automatically
// Only checked in explicit operations

Underflow

Message: "Numeric underflow: {0}"

Code: Overflow

Type Errors - ErrorCode 0x02XX

ArityMismatch

Message: "Arity mismatch: expected {expected} arguments, got {got}"

Code: VmError

// Function expects 2 args, gets 1
ese add(a, b) { pada a + b; }
ayanmo result = add(5);

ArgumentError

Message: "Argument error: {0}"

Code: VmError

// Invalid argument value
ayanmo result = Obara.gbongbo(-5);

TypeError

Proverb: "Ki i se gbogbo eye lo n fo. (Not all birds can fly.)"

Code: TypeMismatch

// Type mismatch in operation
ayanmo result = "hello" - 5;

ConversionError

Message: "Cannot convert {from} to {to}"

Code: InvalidCast

Index/Key Errors (Ogunda / Ika) - ErrorCode 0x01XX

IndexOutOfBounds

Proverb: "Eni to gbera le opin, yoo subu. (One who goes beyond the edge will fall.)"

Code: OutOfBounds

ayanmo list = [1, 2, 3];
ayanmo item = list[5];

KeyNotFound

Proverb: "A ki i wa ohun ti ko si. (One cannot find what does not exist.)"

Code: OutOfBounds

ayanmo map = {"name": "Alice"};
ayanmo age = map["age"];

SpannedError

Errors with source location information for clear debugging:

ERROR at main.ifa:10:5: TypeError: expected Int, got Str
  10 | ayanmo result = "hello" + 5;
     |      ^
  Hint: Ki i se gbogbo eye lo n fo. (Not all birds can fly.)

SpannedError includes:

  • Source file, line, column
  • The source line with a caret pointing to the error
  • A Yoruba proverb for educational context

Error Handling

Try-Catch

gbiyanju {
    ayanmo result = risky_operation();
} gba (error) {
    Irosu.fo("Error: " + error);
} nipari {
    cleanup();
}

// English style
try {
    ayanmo result = risky_operation();
} catch (error) {
    Irosu.fo("Error: " + error);
} finally {
    cleanup();
}

Assertions

// Yoruba
Okanran.sise(x >= 0, "x must be non-negative");

// English
Okanran.assert(x >= 0, "x must be non-negative");
