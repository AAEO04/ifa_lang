types.ifa

Type System Reference

Dynamic Types in IfaValue

Overview

Ifa-Lang uses a dynamic type system. All values are instances of IfaValue, a 32-byte tagged union enum. The actual implementation is in crates/ifa-types/src/value_union.rs.

Core Types

Primitive Types

Int

64-bit signed integer

ayanmo x = 42;
ayanmo negative = -1000;
  • Range: -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807
  • Inlined directly in the enum (no heap alloc)
  • Small ints 0-255 cached in a static pool

Float

64-bit floating point number

ayanmo pi = 3.14159;
ayanmo scientific = 1.23e-4;
  • IEEE 754 double precision
  • Inlined directly in the enum (no heap alloc)

Bool

Boolean value

ayanmo truth = otito;
ayanmo lies = iro;
  • Values: otito (true), iro (false)
  • English aliases: true, false

Null

Null/empty value

ayanmo empty = ofifo;
ayanmo nothing = null;
  • Represents absence of value
  • Falsy in boolean context

String Type (CompactString)

Str

Unicode string with Small String Optimization

ayanmo name = "Ifa-Lang";
ayanmo yoruba = "Kaabo awuju!";
  • UTF-8 encoded
  • Small String Optimization: strings up to 21 bytes stored inline (no heap alloc)
  • Strings longer than 21 bytes stored as Arc<str> (heap-allocated, ref-counted)
  • Methods: Ika string operations

Collection Types

List

Ordered collection of values

ayanmo numbers = [1, 2, 3, 4, 5];
ayanmo mixed = [1, "hello", otito, 3.14];
  • Wrapped in Arc<Vec<IfaValue>> (heap-allocated, ref-counted)
  • Dynamic typing (mixed types allowed)
  • Zero-based indexing with negative indexing support
  • Methods: Ogunda collection operations

Map

Key-value dictionary

ayanmo person = {
    "name": "Alice",
    "age": 30,
    "active": otito
};
  • Wrapped in Arc<HashMap<CompactString, IfaValue>>
  • String keys only (CompactString for SSO)
  • Any value types

Function Types

Fn

Callable function reference

ese add(a, b) {
    pada a + b;
}
ayanmo func = add;
ayanmo result = func(5, 3);
  • First-class functions
  • Wrapped in Arc<BytecodeFnData>

Closure

Function with captured environment

ese make_adder(x) {
    pada { y -> x + y };
}
ayanmo add5 = make_adder(5);
ayanmo result = add5(3);
  • Bytecode closures: function template + captured upvalues
  • Upvalues use Arc<Mutex<IfaValue>> for by-reference capture

Result

Ok/Err wrapper for error handling

// A function returning Result
ayanmo result = Odi.ka("data.txt");
// Result can be Ok(value) or Err(value)
  • Boxed ResultPayload { Ok(IfaValue) | Err(IfaValue) }
  • Used by domain methods that can fail

Resource

Opaque resource handle

ayanmo file = Odi.si("data.txt");
  • Wrapped in Arc<ResourceToken>
  • Opaque handles for safe resource management
  • Domain-specific operations

VM-Specific Types

Available when VM feature is enabled (#![feature = "vm"]):

  • AstFn: AST function representation (interpreter path)
  • Upvalue: Captured binding cell for closures
  • Future: Async future value (Pending/Ready)
  • Actor: Actor handle (id + type-erased channel sender)
  • Return: Return wrapper for function return values
  • Break: Loop break signal
  • Continue: Loop continue signal

Memory Layout

IfaValue Size

  • Total: 32 bytes on 64-bit systems (confirmed by test)
  • This is a regular Rust enum, size driven by discriminator + largest variant

CompactString Layout

  • Inline branch: { len: u8, char_len: u8, data: [u8; 21] } — 23 bytes total
  • Heap branch: Arc<str> (pointer + length = 16 bytes)
  • SSO threshold: 21 bytes — strings up to 21 UTF-8 bytes stored inline

Type Conversions

Implicit Conversion

// Numeric promotion
ayanmo result = 5 + 3.14;  // Int -> Float

// String concatenation
ayanmo message = "Value: " + 42;  // Int -> Str

// Boolean context via is_truthy()
// Null, false, 0, 0.0, NaN, empty collections are falsy

Equality Semantics

is_equal() compares structurally:

  • Int/Float cross-type comparison with numeric promotion
  • Float comparison uses epsilon (f64::EPSILON)
  • List/Map comparison deep-equals element by element
  • Arc pointer-equality shortcut for List/Map (same Arc = equal)

Serialization

IfaValue supports serde with bincode-compatible surrogate enum:

  • Serializable: Null, Bool, Int, Float, Str, List
  • Non-serializable: Fn, AstFn, Closure, Future, Actor, Resource, Upvalue, Result, Return, Break, Continue
