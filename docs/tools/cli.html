cli.ifa

CLI Reference

Command line interface for Ifa-Lang

Note: If the first argument is not a known subcommand and does not start with -, run is automatically inserted. ifa hello.ifa is equivalent to ifa run hello.ifa.

Run & Execute

ifa run <file>

Execute an Ifa-Lang source file using the interpreter. Automatically runs Babalawo static analysis before execution.

ifa run hello.ifa
FlagDescription
--sandboxEnable sandbox isolation
--allow-allGrant all capabilities
--allow-readAllow file read access
--allow-writeAllow file write access
--allow-netAllow network access
--allow-envAllow environment access
--allow-timeAllow time access
--allow-randomAllow random access
--allow-jsAllow JavaScript FFI
--allow-pythonAllow Python FFI

ifa runb <file.ifab>

Run compiled bytecode. Requires a matching .ifa source file in the same directory for Babalawo verification — bytecode cannot run standalone.

ifa runb program.ifab
FlagDescription
--forceSkip Babalawo verification
--allow-allGrant all capabilities
--allow-readAllow file read access
--allow-writeAllow file write access
--allow-netAllow network access
--allow-envAllow environment access
--allow-timeAllow time access
--allow-randomAllow random access
--allow-jsAllow JavaScript FFI
--allow-pythonAllow Python FFI

ifa repl

Start the interactive REPL.

ifa repl

Build & Compile

ifa bytecode <file>

Compile an .ifa source file to .ifab bytecode.

ifa bytecode main.ifa -o main.ifab
FlagDefaultDescription
-o, --output <path><file>.ifabOutput path

ifa build <file>

Transpile to Rust via ifa-transpiler, then compile to a native binary. Requires Rust toolchain.

ifa build main.ifa -o myapp
FlagDescription
-o, --output <path>Output binary path
--target <triple>Cross-compilation target triple
--projectBuild as an Oja project

Check, Lint & Format

ifa check <file>

Parse and run Babalawo static analysis without executing.

ifa check myprogram.ifa

ifa babalawo <path>

Run the Babalawo linter with proverb-based error messages.

ifa babalawo script.ifa --strict --format verbose
FlagDescription
--strictEnable all lint passes
--format json|compact|verboseOutput format
--fastSkip expensive analyses
--taboo <caller:callee>Enforce caller/callee taboo constraints

ifa fmt <file>

Format Ifa-Lang source code.

ifa fmt src/*.ifa --check
ifa fmt src/*.ifa
FlagDescription
--unstableAcknowledge formatter is still experimental
--checkCheck only, do not modify

Test

ifa test [path]

Run Ifa-Lang test files. Matches files named *_test.ifa or test_*.ifa.

ifa test
ifa test tests/ --verbose
FlagDescription
-v, --verboseShow detailed test output

Documentation

ifa doc <input> <output>

Generate HTML documentation from .ifa source files.

ifa doc src/ docs/

Other Commands

ifa deploy

Zero-config deployment scanner for the current directory.

ifa flash <file> --target <target>

Flash compiled bytecode to an embedded device. Targets: esp32, stm32, rp2040.

ifa debug --file <path>

Start the Debug Adapter Protocol (DAP) server.

ifa lsp

Start the Language Server Protocol server on stdin/stdout.

ifa version

Display version information.

ifa self-update

Update Ifá-Lang to the latest version.
