IDE Integration

Set up your editor for Ifa-Lang development

Language Server Protocol (LSP)

Ifa-Lang includes a built-in LSP server for IDE integration. Start it with ifa lsp.

Features

  • Syntax highlighting for keywords and Odu domains
  • Auto-completion for domain methods, keywords, variables
  • Diagnostics for parse errors and type warnings from Babalawo
  • Real-time error checking via document sync

Visual Studio Code

settings.json

{
    "ifa.linter.enabled": true,
    "ifa.linter.strict": false,
    "ifa.format.onSave": true,
    "ifa.lsp.path": "ifa",
    "ifa.lsp.args": ["lsp"],
    "[ifa]": {
        "editor.tabSize": 4,
        "editor.insertSpaces": true,
        "editor.formatOnSave": true
    }
}

Neovim

With nvim-lspconfig

local lspconfig = require('lspconfig')
local configs = require('lspconfig.configs')

if not configs.ifa_babalawo then
    configs.ifa_babalawo = {
        default_config = {
            cmd = { 'ifa', 'lsp' },
            filetypes = { 'ifa' },
            root_dir = lspconfig.util.root_pattern('ifa.toml', '.git'),
            settings = {},
        },
    }
end

lspconfig.ifa_babalawo.setup{}

Emacs

With lsp-mode

(use-package lsp-mode
  :hook (ifa-mode . lsp)
  :commands lsp)

(lsp-register-client
  (make-lsp-client
    :new-connection (lsp-stdio-connection '("ifa" "lsp"))
    :major-modes '(ifa-mode)
    :server-id 'ifa-babalawo))

JetBrains IDEs

Install "Generic LSP Client" plugin and add server:

  • Name: Ifa-Lang
  • Command: ifa lsp
  • File patterns: *.ifa

File Association

Ifa-Lang source files use the .ifa extension:

*.ifa          Ifa-Lang source code
*.ifab         Ifa-Lang bytecode (compiled)
