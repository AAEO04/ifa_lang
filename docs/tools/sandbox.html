Sandbox

Secure runtime isolation and capability-based security

The ifa-sandbox crate provides a deny-by-default security model for running untrusted Ifa-Lang code safely.

Source: crates/ifa-sandbox/src/

Ofun Capability System

The Ofun enum defines all capabilities. No code can access system resources without explicit grants:

enum Ofun

pub enum Ofun {
    ReadFiles { root: PathBuf },
    WriteFiles { root: PathBuf },
    Network { domains: Vec<String> },
    Execute { programs: Vec<String> },
    Environment { keys: Vec<String> },
    Time,
    Random,
    Stdio,
    Crypto,
    Bridge { language: String },
}

CapabilitySet

Collection of granted capabilities, passed to interpreter/VM for runtime enforcement.

let mut caps = CapabilitySet::new();
caps.grant(Ofun::Stdio);
caps.grant(Ofun::ReadFiles { root: "/tmp".into() });

if caps.has(&Ofun::Time) {
    // allowed
}

Runtime Integration

CapabilitySet is passed to the interpreter or VM via Esu (the crossroads). Each domain's dispatch checks capabilities through Esu::enforce_crossroads() before performing operations.

let sandbox = Sandbox::new(config);
sandbox.grant_capability(Ofun::Stdio);
assert!(sandbox.has_capability(Ofun::Stdio));

OmniBox (WASM Isolation)

Complete isolation via WebAssembly, with WASI context built from CapabilitySet:

let omnibox = OmniBox::new(config);
let result = omnibox.run(bytecode)?;
