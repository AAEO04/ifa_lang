Ebo (Rituals)

Structured workflows with Ebo

Ebo: Sacred Rituals

In Yoruba tradition, Ebo (ritual sacrifice) is a structured ceremony for transformation. In Ifá-Lang, an Ebo is a scoped block of code that runs and can be dismissed. The keyword ebo creates a ritual scope.

Basic Ebo

Simple Ritual 
// Ebo scopes group code with lifecycle management
ebo "my-ritual" {
    Irosu.fo("Performing ritual...");
    ayanmo result = 42;
    Irosu.fo("Result: " + result);
}
// Ebo auto-dismisses at end of scope

Ebo with Explicit Lifecycle

Create and dismiss an Ebo explicitly using the Oyeku domain:

Ebo Lifecycle 
// Oyeku (the Odù of spirits) manages Ebo
ayanmo ritual = Oyeku.ebo("init-ritual");

// Work inside the ritual
Irosu.fo("Initializing...");

// Dismiss the ritual explicitly
ritual.dismiss();
Irosu.fo("Ritual complete");

Ebo with State

Ritual with State 
ebo "counter-ritual" {
    ayanmo count = 0;
    
    fun i ninu range(1, 6) {
        ayanmo count = count + i;
    }
    
    Irosu.fo("Total: " + count);  // 15
}
Note

Ebo scopes ensure cleanup of resources. The dismiss() method releases any resources associated with the ritual. The ebo keyword version auto-dismisses at scope exit.

What You Learned

  • Ebo scopes with ebo "name" { ... }
  • Explicit lifecycle with Oyeku.ebo() and dismiss()
  • Automatic cleanup at scope exit
