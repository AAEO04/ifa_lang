    35. Advanced Operators & Collections

    Power, null coalescing, references, compound assignment, Set literals, interpolated strings

    1. Power Operator **

    Exponentiation with ** works on integers and floats:

    ayanmo squared = 4 ** 2;     // 16
ayanmo cubed = 2 ** 3;       // 8
ayanmo root = 9 ** 0.5;      // 3.0
ayanmo big = 10 ** 6;        // 1_000_000

    This is shorthand for Obara.agbara(base, exp).

    2. Null Coalescing ??

    The ?? operator returns the left side if it is not null, otherwise the right side:

    ayanmo name = Irosu.gbo("Enter name: ");
ayanmo display = name ?? "Guest";
Irosu.fo("Hello, " + display);

// Chaining
ayanmo config = env ?? file_config ?? defaults();

    3. AddressOf & and Dereference *

    Ifá-Lang supports low-level pointer operations through domain methods, but & and * operators work on references:

    ayanmo x = 42;
ayanmo ref = &x;      // Take a reference
Irosu.fo(*ref);       // 42 — dereference

// Mutable reference
ayanmo y = [1, 2, 3];
ayanmo mut_ref = &mut y;
Ogbontarigi.fi(mut_ref, 4);  // Mutate through reference

    These are primarily used when interfacing with low-level or FFI code. The GC-tracked types (List, Map, String) do not require manual dereferencing.

    4. Compound Assignment

    Augmented assignment operators modify a variable in place:

    ayanmo score = 10;
score += 5;    // 15
score -= 3;    // 12
score *= 2;    // 24
score /= 4;    // 6
score %= 3;    // 0

// Works with strings (concat-assign)
ayanmo greeting = "Hello ";
greeting += "World";  // "Hello World"

    5. Set Literals

    Ifá-Lang supports Set literals using Set { ... } syntax. Sets are unordered collections of unique values:

    // Create a set
ayanmo colors = Set { "red", "green", "blue" };

// Sets deduplicate automatically
ayanmo unique = Set { 1, 2, 2, 3, 3, 3 };
Irosu.fo(unique);  // Set { 1, 2, 3 }

// Check membership (via Ogunda)
ayanmo has_red = Ogunda.wa(colors, fn(c) { c == "red" });

    6. Interpolated Strings

    String interpolation with $"..." embeds expressions directly in strings:

    ayanmo name = "Ifá";
ayanmo version = 2;

// Basic interpolation
Irosu.fo($"Hello {name}!");  // Hello Ifá!

// Expressions inside
Irosu.fo($"Version {version + 1}.0");  // Version 3.0

// Method calls
Irosu.fo($"Today is {Iwori.bayi()}");

    Interpolated strings are more readable than concatenation:

    // Without interpolation
Irosu.fo("User " + name + " scored " + score + " points");

// With interpolation
Irosu.fo($"User {name} scored {score} points");
