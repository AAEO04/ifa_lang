Math II: Oturupon

Subtraction, division, and modulo

Oturupon: The Odù of Balance

Oturupon governs subtraction, division, and transformations — the operations that reduce and partition. Where Obara (Lesson 7) handles addition/multiplication/aggregation, Oturupon handles the inverse operations.

Subtraction

Subtract 
// Checked subtraction (errors on overflow)
ayanmo result = Oturupon.din(100, 25);
Irosu.fo(result);  // 75

// Also available with native operator
ayanmo diff = 100 - 25;
// Checked subtraction (errors on overflow)
let result = Oturupon.sub(100, 25);
Irosu.println(result);  // 75

// Also available with native operator
let diff = 100 - 25;

Division

Divide

ayanmo quotient = Oturupon.pin(10, 3);

// Integer division (truncates)
ayanmo integer_div = Oturupon.pin_odidi(10, 3);

// Float division
let quotient = Oturupon.div(10, 3);
Irosu.println(quotient);  // 3.333...

// Integer division (truncates)
let integer_div = Oturupon.div(10, 3);
Irosu.println(integer_div);  // 3
Division by Zero

Division by zero raises an error with Oturupon. Use try/catch to handle it gracefully.

Modulo

Modulo 
// Standard modulo
ayanmo remainder = Oturupon.ku(17, 5);
Irosu.fo(remainder);  // 2

// Euclidean modulo (always non-negative)
ayanmo euclid = Oturupon.ku_euclidean(-3, 7);
Irosu.fo(euclid);  // 4  (instead of -3)

Negation

Negate 
ayanmo neg = Oturupon.dake(42);
Irosu.fo(neg);  // -42

ayanmo pos = Oturupon.dake(-10);
Irosu.fo(pos);   // 10

Reciprocal

Reciprocal

Practical: Statistics

Stats Calculator 
isodale average(list) {
    Oturupon.pin(Obara.apapo(list), Ogbe.iye_ohun(list))
}

isodale variance(list) {
    ayanmo avg = average(list);
    ayanmo squared_diffs = Ogunda.yi_pada(list, { x -> (x - avg) * (x - avg) });
    Oturupon.pin(Obara.apapo(squared_diffs), Ogbe.iye_ohun(list))
}

ayanmo data = [10, 20, 30, 40, 50];
Irosu.fo("Mean: " + average(data));
Irosu.fo("Variance: " + variance(data));
fn average(list) {
    Oturupon.div(Obara.apapo(list), Ogbe.iye_ohun(list))
}

fn variance(list) {
    let avg = average(list);
    let squared_diffs = Ogunda.yi_pada(list, { x -> (x - avg) * (x - avg) });
    Oturupon.div(Obara.apapo(squared_diffs), Ogbe.iye_ohun(list))
}

let data = [10, 20, 30, 40, 50];
Irosu.println("Mean: " + average(data));
Irosu.println("Variance: " + variance(data));
