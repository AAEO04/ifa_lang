Files

Reading and writing files with Odi domain

Feature Gate

Odi (the Odù of boundaries) governs filesystem operations and requires the backend feature flag in your Ifa.toml.

Reading Files

Reading a File 
// Read entire file as string
ayanmo content = Odi.ka("hello.txt");
Irosu.fo(content);

Writing Files

Writing a File 
// Write string to file (overwrites)
Odi.kọ("output.txt", "Hello, Ifá-Lang!");

Appending to Files

Appending 
// Append to file
Odi.fikun("log.txt", "New log entry");

Checking Files

File Checks 
// Check if file exists
ayanmo exists = Odi.wà("data.txt");  // otito or iro

// Delete file
Odi.pa("temp.txt");

What You Learned

  • Reading: Odi.ka()
  • Writing: Odi.kọ()
  • Appending: Odi.fikun()
  • Existence: Odi.wà()
  • Deletion: Odi.pa()
  • Requires backend feature flag
