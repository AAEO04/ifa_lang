Reactivity

Signals, computed values, and effects

Àjọṣe: Reactive Relationships

Ifá-Lang includes a built-in reactive framework called Àjọṣe (Yoruba: "interaction"). It provides signals, computed values, and effects — similar to Solid.js or MobX. Use it to create reactive data flows in your programs.

Signals

Create a reactive signal with an initial value:

Signal 
// Create a signal
ayanmo count = Signal(0);

// Read the current value
Irosu.fo("Count: " + count.peek());

// Update the signal
count.update(5);
Irosu.fo("Count: " + count.peek());  // 5
// Create a signal
let count = Signal(0);

// Read the current value
Irosu.println("Count: " + count.peek());

// Update the signal
count.update(5);
Irosu.println("Count: " + count.peek());  // 5

Computed Values

Derive values from signals that update automatically:

Computed 
ayanmo count = Signal(10);
ayanmo doubled = Computed({ -> count.peek() * 2 });

Irosu.fo("Doubled: " + doubled.peek());  // 20

count.update(25);
Irosu.fo("Doubled: " + doubled.peek());  // 50

Effects

Run side effects that re-run when their dependencies change:

Effect 
ayanmo name = Signal("Ifá");
ayanmo age = Signal(1000);

effect({
    -> Irosu.fo(name.peek() + " is " + age.peek() + " years old")
});

// Changing a signal re-runs the effect
name.update("Ọba");  // prints "Ọba is 1000 years old"

Ajose Bindings

Use direct reactive bindings with the ajose keyword:

Ajose 
ayanmo a = Signal(5);
ayanmo b = Signal(3);

// Reactive binding: c auto-updates when a or b change
ayanmo c = Computed({ -> a.peek() + b.peek() });

Irosu.fo("c = " + c.peek());  // 8
a.update(10);
Irosu.fo("c = " + c.peek());  // 13
let a = Signal(5);
let b = Signal(3);

// Reactive binding: c auto-updates when a or b change
let c = Computed({ -> a.peek() + b.peek() });

Irosu.println("c = " + c.peek());  // 8
a.update(10);
Irosu.println("c = " + c.peek());  // 13
Reactive Domains

For async patterns like polling, event loops, and file watching, combine Àjọṣe reactivity with the Osa domain (async concurrency). See lesson 25 for the full Osa concurrency guide.

What You Learned

  • Computed values: Computed({ -> expr })
