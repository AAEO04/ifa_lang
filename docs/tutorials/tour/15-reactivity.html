Reactivity

Reactive programming patterns

Planned Feature

Ifá-Lang does not yet have a built-in reactive framework (a dedicated Àjọṣe reactivity system is planned). For now, reactive patterns can be achieved using the Osa domain (async polling) and standard Ifá-Lang constructs.

Polling with Osa

Use Osa.ṣe_atunṣe() (interval) and Osa.reti() (delay) to create reactive polling loops:

Polling Pattern 
// Poll a data source every 2 seconds
isọdẹlẹ poll_data() {
    ayanmo i = 0;
    nigba (i < 5) {
        ayanmo data = daro Osa.reti(2000);  // wait 2 seconds
        Irosu.fo("Poll " + (i + 1) + ": checking for updates...");
        ayanmo i = i + 1;
    }
    Irosu.fo("Done polling");
}

poll_data();

Interval-based Updates

Interval Pattern 
// Check a file for changes
isọdẹlẹ watch_file(path, interval_ms) {
    ayanmo last_content = Odi.ka(path);
    
    fun i ninu range(0, 10) {
        daro Osa.reti(interval_ms);
        ayanmo current = Odi.ka(path);
        
        ti (current != last_content) {
            Irosu.fo("File changed!");
            ayanmo last_content = current;
        }
    }
}

Event-driven with Osa

Async Event Loop 
// Simulated async event loop
isọdẹlẹ event_loop() {
    ayanmo running = otito;
    
    nigba (running) {
        ayanmo event = daro Osa.reti(1000);  // wait 1 second
        
        ti (event != ofifo) {
            Irosu.fo("Processing event...");
        }

}
Osa: The Odù of Async

Osa (the Odù of movement) handles asynchronous operations. It is feature-gated behind backend. Key methods: Osa.reti() (delay/await), Osa.ṣe_atunṣe() (interval).

Àjọṣe (Planned)

A dedicated reactive framework called Àjọṣe (Yoruba: "interaction") is planned. It will provide signals, computed values, effects, and subscriptions -- similar to Solid.js or MobX. Stay tuned for future releases.

What You Learned

  • Async event loops with Osa domain
  • File watching as a reactive pattern
  • Osa requires backend feature flag
