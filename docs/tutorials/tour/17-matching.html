Pattern Matching

Match expressions for clean branching

Yàn: Choose by Pattern

The yàn / match expression lets you branch based on value patterns. It's more expressive than chained if/else — you match against literal values, ranges, or wildcards.

Basic Match

Match a value against literal patterns:

Literal Matching 
ayanmo code = 200;

yan (code) {
    200 => Irosu.fo("OK");
    404 => Irosu.fo("Not Found");
    500 => Irosu.fo("Server Error");
    _   => Irosu.fo("Unknown code");
}
let code = 200;

match (code) {
    200 => Irosu.println("OK");
    404 => Irosu.println("Not Found");
    500 => Irosu.println("Server Error");
    _   => Irosu.println("Unknown code");
}

Range Patterns

Match against numeric ranges with ..:

Range Matching 
ayanmo score = 85;

yan (score) {
    90..100 => Irosu.fo("A grade");
    80..89  => Irosu.fo("B grade");
    70..79  => Irosu.fo("C grade");
    60..69  => Irosu.fo("D grade");
    _       => Irosu.fo("F grade");
}
let score = 85;

match (score) {
    90..100 => Irosu.println("A grade");
    80..89  => Irosu.println("B grade");
    70..79  => Irosu.println("C grade");
    60..69  => Irosu.println("D grade");
    _       => Irosu.println("F grade");
}

Wildcard Pattern

The _ wildcard matches anything (like default in other languages):

Wildcard 
ayanmo x = 42;

yan (x) {
    0   => Irosu.fo("zero");
    1   => Irosu.fo("one");
    _   => Irosu.fo("something else");
}
// Prints: "something else"

Matching Multiple Values

Multi-branch 
isodale describe(n) {
    yan (n) {
        1 => "one";
        2 => "two";
        3..10 => "between 3 and 10";
        _ => "more than 10";
    }
}

Irosu.fo(describe(5));   // "between 3 and 10"
Irosu.fo(describe(1));   // "one"
Irosu.fo(describe(99));  // "more than 10"
fn describe(n) {
    match (n) {
        1 => "one";
        2 => "two";
        3..10 => "between 3 and 10";
        _ => "more than 10";
    }
}

Irosu.println(describe(5));   // "between 3 and 10"
Irosu.println(describe(1));   // "one"
Irosu.println(describe(99));  // "more than 10"

Matching on Strings

String Matching 
ayanmo command = "start";

yan (command) {
    "start"  => Irosu.fo("Starting...");
    "stop"   => Irosu.fo("Stopping...");
    "status" => Irosu.fo("Checking status...");
    _        => Irosu.fo("Unknown command");
}

When to Use Match vs If/Else

Best Practices

Use yàn/match when you're checking one value against many possible patterns. Use ti/if when you have complex boolean conditions or multiple unrelated checks. Match is also excellent when you must handle every case — the wildcard _ ensures exhaustiveness.
