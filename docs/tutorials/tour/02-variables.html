Variables & Types

Storing and working with data

Declaring Variables

In Ifá-Lang, you declare variables using ayanmo (Yoruba: "destiny") or its English alias let:

variables.ifa 
// Declaring variables (Yoruba style)
ayanmo oruko = "Ifá";
ayanmo iye = 42;
// Declaring variables (English style)
let name = "Ifá";
let count = 42;
Why "ayanmo"?

In Yoruba philosophy, ayanmọ́ means "destiny" or "fate". When you declare a variable, you're declaring its destiny -- what it will hold.

Data Types

Ifá-Lang has these built-in types:

Type Example Description
Number 42, 3.14 Integers and floats
String "Hello" Text enclosed in quotes
Boolean otito, iro True (otito/true) or False (iro/false)
List [1, 2, 3] Ordered collection
Null ofifo Absence of value
Map {"key": val} Key-value dictionary

Constant Declarations

Use const (English) or ayanfe (Yoruba: "chosen") for compile-time constant values that never change:

Constants 
// Constants are inlined at compile time
ayanfe MAX_RETRIES = 3;
ayanfe APP_NAME = "Ifá";

ayanmo x = MAX_RETRIES;  // inlined to 3
// Constants are inlined at compile time
const MAX_RETRIES = 3;
const APP_NAME = "Ifá";

let x = MAX_RETRIES;  // inlined to 3

Maps (Dictionaries)

Maps store key-value pairs using { key: value } syntax:

Maps 
// Creating maps
ayanmo user = { "name": "Ifá", "age": 1000 };

// Access by key
ayanmo name = user["name"];

// Nested maps
ayanmo config = {
    "db": { "host": "localhost", "port": 5432 }
};
ayanmo port = config["db"]["port"];
// Creating maps
let user = { "name": "Ifá", "age": 1000 };

// Access by key
let name = user["name"];

// Nested maps
let config = {
    "db": { "host": "localhost", "port": 5432 }
};
let port = config["db"]["port"];

Working with Variables

Working with Data 
// Numbers
ayanmo age = 25;
ayanmo price = 19.99;
ayanmo total = age + price;  // 44.99

// Strings
ayanmo first = "Ọba";
ayanmo last = "Adé";
ayanmo full = first + " " + last;  // "Ọba Adé"

// Booleans
ayanmo active = otito;   // true
ayanmo complete = iro;   // false

// Lists
ayanmo numbers = [1, 2, 3, 4, 5];
ayanmo names = ["Ọba", "Adé", "Ifá"];
// Numbers
let age = 25;
let price = 19.99;
let total = age + price;  // 44.99

// Strings
let first = "Ọba";
let last = "Adé";
let full = first + " " + last;  // "Ọba Adé"

// Booleans
let active = true;
let complete = false;

// Lists
let numbers = [1, 2, 3, 4, 5];
let names = ["Ọba", "Adé", "Ifá"];

Type Checking

Use Ofun.iru() to check a value's type:

Checking Types 
ayanmo x = 42;
ayanmo t = Ofun.iru(x);
Irosu.fo(t);  // "Int"

ayanmo s = "Hello";
Irosu.fo(Ofun.iru(s));  // "Str"

ayanmo list = [1, 2, 3];
Irosu.fo(Ofun.iru(list));  // "List"

ayanmo map = {"a": 1};
Irosu.fo(Ofun.iru(map));  // "Map"
let x = 42;
let t = Ofun.iru(x);
Irosu.println(t);  // "Int"

let s = "Hello";
Irosu.println(Ofun.iru(s));  // "Str"

let list = [1, 2, 3];
Irosu.println(Ofun.iru(list));  // "List"

let map = {"a": 1};
Irosu.println(Ofun.iru(map));  // "Map"

String Concatenation

Use + to join strings and other values:

Concatenation 
ayanmo name = "Ifá";
ayanmo age = 1000;

Irosu.fo("Name: " + name);
Irosu.fo("Age: " + age);  // Numbers auto-convert
let name = "Ifá";
let age = 1000;

Irosu.println("Name: " + name);
Irosu.println("Age: " + age);  // Numbers auto-convert
