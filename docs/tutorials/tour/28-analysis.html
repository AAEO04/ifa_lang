Static Analysis

Compile-time checking with Babalawo

Babalawo: The Wise Priest

Babalawo (Babaláwo = "father of secrets") is Ifá-Lang's static analyzer. It checks your code for type errors, taboo violations, resource leaks, and provides culturally-grounded diagnostic messages using Yoruba proverbs.

Running Babalawo

CLI Usage 
# Analyze a single file
ifa babalawo script.ifa

# Analyze an entire project
ifa babalawo src/

# Strict mode (all warnings as errors)
ifa babalawo src/ --strict

# Check without running (also runs Babalawo)
ifa check script.ifa

# Fast mode (skips deep analysis)
ifa babalawo src/ --fast

Output Formats

Formats 
# Default: human-readable with proverbs
ifa babalawo script.ifa

# Compact: one line per diagnostic
ifa babalawo script.ifa --format compact

# Verbose: full context and suggestions
ifa babalawo script.ifa --format verbose

# JSON: machine-readable (for editor integration)
ifa babalawo script.ifa --format json

What Babalawo Checks

Check Description
Type Inference Infers types of expressions and detects type mismatches
Taboo Violations Enforces domain-restriction declarations
Borrow/Lifetime Ìwà engine tracks resource lifecycles and move semantics
Capability Inference Infers what capabilities a program requires
Resource Debt Tracks unclosed resources and missing cleanup
Odu Method Validation Validates domain method names and signatures

Proverb Diagnostics

Babalawo uses Yoruba proverbs aligned to specific error patterns:

Proverb Example 
# Ifa babalawo script.ifa

# Output:
# [Warning] Unused variable 'temp' at line 5:23
#   "Bi a ba n ró̀ró̀ lọ́wọ́, a kò níí dánù àgbàdo"
#   (If we act with purpose, we will not waste corn)
#   Suggestion: Remove or prefix with _temp

# [Error] Division by zero at line 8:12
#   "Kò sí ònà tí a ò gbà gbà lórí ojúnà"
#   (There is no path that does not lead somewhere)
#   Suggestion: Add a check before division

Integration with Run

Babalawo automatically runs before execution in ifa run and ifa runb:

Auto-Check 
# Babalawo checks before executing
ifa run script.ifa  # analyzes first, then runs if no errors

# Bytecode also requires matching source for verification
ifa runb compiled.ifab  # re-parses .ifa for Babalawo check
Safety First

Babalawo is not optional — it's deeply integrated. Even ifa runb for precompiled bytecode re-parses the original source to verify integrity before execution.
