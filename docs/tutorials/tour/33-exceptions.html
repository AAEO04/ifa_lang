    33. Exceptions

    Try, Catch, Finally, and Throw

    While Okanran provides assertion methods, Ifá-Lang also has full exception handling with try / catch / finally blocks and the throw statement for raising errors.

    1. Throwing Exceptions

    Use ta / throw to raise an exception. The value can be any type — typically a string message:

    // Throw a string error
ta "Something went wrong";

// Throw with an integer code
ta 404;

// Throw inside a condition
ti (file_not_found) {
    ta "File not found: " + path;
}

    When thrown, the exception unwinds the call stack until a matching catch is found. If none is found, the program halts with an error message.

    2. Try / Catch

    Wrap risky code in gbiyanju / try and handle errors in gba / catch:

    gbiyanju {
    ayanmo data = Odi.ka("/etc/config.ifa");
    Irosu.fo("Config loaded: " + data);
} gba (err) {
    Irosu.kigbe("Failed to load config: " + err);
}

    The catch variable (err) captures the thrown value. You can inspect it and recover:

    gbiyanju {
    ayanmo result = risky_operation();
    Irosu.fo("Result: " + result);
} gba (e) {
    // Inspect error type
    ti (Okanran.dogba(e, "timeout")) {
        Irosu.fo("Retrying...");
        // Retry logic here
    } bibeko {
        Irosu.kigbe("Unhandled error: " + e);
        ta e;  // Re-throw
    }
}

    3. Finally — Cleanup That Always Runs

    nipari / finally blocks execute regardless of whether the try block succeeded or threw:

    ayanmo file = Odi.si("data.txt");
gbiyanju {
    ayanmo content = Odi.ka_file(file);
    Irosu.fo(content);
} nipari {
    Odi.pa(file);  // Always close the file
}

    Finally runs after the try block completes, or after the catch block if one exists. It runs even if the catch block re-throws.

    4. Try / Catch / Finally Together

    gbiyanju {
    ayanmo server = Otura.de(":8080");
    Irosu.fo("Server started");
} gba (err) {
    Irosu.kigbe("Server error: " + err);
    ta err;
} nipari {
    Irosu.fo("Server attempt finished");
}

    5. Error Propagation with ?

    Use the ? operator (try operator) to propagate errors up the call stack:

    ese load_config(path) {
    // If read fails, the error propagates to the caller
    ayanmo content = Odi.ka(path)?;
    pada parse_config(content);
}

ese main() {
    gbiyanju {
        ayanmo cfg = load_config("/etc/config.ifa")?;
        Irosu.fo("Config: " + cfg);
    } gba (e) {
        Irosu.kigbe("Error: " + e);
    }
}

    When a function call is followed by ?, an error return is automatically converted to a throw in the calling context.
