Errors

Assertions and error handling with Okanran

Okanran: The Odù of Challenges

In Yoruba tradition, Okanran represents challenges and obstacles. In Ifá-Lang, the Okanran domain handles error handling, assertions, and exceptions.

Assertions (beeni / sise)

Use Okanran.beeni() to assert conditions are true:

Assertions 
ayanmo x = 42;

// Assert that x equals 42
Okanran.beeni(x == 42, "x should be 42");

// Assert that x is greater than 0
Okanran.sise(x > 0, "x must be positive");

Checking Conditions

Condition Checks 
Okanran.dogba(a, b);           // assert equal
Okanran.yato(a, b);            // assert not equal
Okanran.beko(condition, msg);   // assert false
Okanran.ko_si(value, msg);     // assert null/nil

Fallible Operations (gbiyanju)

Use Okanran.gbiyanju() to try an operation with a default fallback:

Try with Fallback 
// Try an operation, use fallback on failure
ayanmo result = Okanran.gbiyanju(
    { -> Odi.ka("maybe_exists.txt") },
    "default content"
);
Irosu.fo(result);  // file content or "default content"

Throwing Errors

Use Okanran.ta() to throw an error:

Throwing 
isọdẹlẹ divide(a, b) {
    ti (b == 0) {
        Okanran.ta("Cannot divide by zero");
    }
    a / b
}

ayanmo result = divide(10, 2);  // 5
// divide(10, 0) would halt with error message

Custom Assertions

Custom Checks 
isọdẹlẹ validate_age(age) {
    Okanran.sise(age >= 0, "Age cannot be negative");
    Okanran.sise(age < 150, "Age seems too high");
    Irosu.fo("Age " + age + " is valid");
}

validate_age(25);   // OK
validate_age(-1);   // halts: "Age cannot be negative"

Proverbs as Error Messages

Okanran includes Yoruba proverbs (Okanran.owe()) for meaningful error context:

Proverbs 
// Get a random Yoruba proverb
ayanmo proverb = Okanran.owe();
Irosu.fo(proverb);  // "Bi a ba nṣe ire, a ko nii ṣe ibi"
Note

Ifá-Lang does not have try/catch blocks. Use Okanran.gbiyanju() for fallible operations with a default value, and Okanran.ta() to halt on unrecoverable errors.

What You Learned

  • Assertions: Okanran.beeni(), Okanran.sise()
  • Equality checks: Okanran.dogba(), Okanran.yato()
  • Fallible operations: Okanran.gbiyanju()
  • Throwing errors: Okanran.ta()
  • Proverbs: Okanran.owe()
