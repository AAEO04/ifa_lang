Maps & Dictionaries

Key-value data structures

Creating Maps

Maps store key-value pairs. Keys are strings, values can be any type:

Map Literals 
// Empty map
ayanmo empty = {};

// String keys with mixed values
ayanmo user = {
    "name": "Ọba Adé",
    "age": 1000,
    "active": otito
};

// Nested maps
ayanmo config = {
    "database": {
        "host": "localhost",
        "port": 5432
    },
    "app": {
        "name": "Ifá-App",
        "debug": iro
    }
};
// Empty map
let empty = {};

// String keys with mixed values
let user = {
    "name": "Ọba Adé",
    "age": 1000,
    "active": true
};

// Nested maps
let config = {
    "database": {
        "host": "localhost",
        "port": 5432
    },
    "app": {
        "name": "Ifá-App",
        "debug": false
    }
};

Accessing Values

Use bracket notation to get and set values:

Access & Mutation 
ayanmo user = { "name": "Ifá", "score": 42 };

// Read
ayanmo name = user["name"];    // "Ifá"

// Write
user["score"] = 100;

// Nested access
ayanmo port = config["database"]["port"];

Map Operations with Ogunda

Ogunda provides key-based operations on maps:

Map Methods 
ayanmo scores = { "alice": 95, "bob": 87, "charlie": 92 };

// Check if key exists
Ogbe.ayika(scores, "alice");       // otito

// Get all keys
ayanmo keys = Ogunda.awon_kokoro(scores);
Irosu.fo(keys);                     // ["alice", "bob", "charlie"]

// Get all values
ayanmo vals = Ogunda.awon_iye(scores);
Irosu.fo(vals);                     // [95, 87, 92]

// Remove a key
Ogunda.yo_key(scores, "bob");
Irosu.fo(scores);                   // { "alice": 95, "charlie": 92 }

Iterating Maps

Map Iteration 
ayanmo inventory = {
    "apples": 10,
    "bananas": 5,
    "cherries": 20
};

// Iterate over keys
fun key ninu Ogunda.awon_kokoro(inventory) {
    ayanmo qty = inventory[key];
    Irosu.fo(key + ": " + qty);
}
let inventory = {
    "apples": 10,
    "bananas": 5,
    "cherries": 20
};

// Iterate over keys
for key in Ogunda.awon_kokoro(inventory) {
    let qty = inventory[key];
    Irosu.println(key + ": " + qty);
}

fn load_config(path) {
    // Parse config from file
    let raw = Odi.ka(path);
    
    // Build structured config
    let cfg = {
        "env": "production",
        "port": 8080,
        "features": {
            "logging": true,
            "metrics": false
        }
    };
    
    cfg
}

let config = load_config("app.ifa.json");
if (config["features"]["logging"]) {
    Irosu.println("Logging enabled");
}
Maps vs Lists

Use Lists for ordered, index-based collections. Use Maps for key-value lookups and structured data. Maps are Ifá-Lang's primary way to represent objects and records.
