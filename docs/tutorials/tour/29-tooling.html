Developer Tooling

LSP, formatter, debugger, REPL, and bytecode

LSP (Language Server)

Ifá-Lang provides a Language Server Protocol implementation for IDE integration:

LSP 
# Start the LSP server (stdin/stdout based)
ifa lsp

# Common editor configuration:
# VS Code: set ifa.lsp.path to "ifa lsp"
# Neovim: use ifa-lsp via lspconfig
# Emacs: configure eglot with ifa lsp

The LSP provides:

  • Completions for domain methods and keywords
  • Diagnostics via Babalawo integration
  • Go-to-definition and hover type info
  • Code actions and suggestions

Code Formatter

Use ifa fmt to format your code. Note: requires --unstable flag:

Format 
# Format a file (requires --unstable)
ifa fmt script.ifa --unstable

# Check formatting without modifying
ifa fmt script.ifa --check --unstable

# Formatter configuration (defaults):
#   indent_size: 4
#   max_width: 100

Debug Adapter Protocol

Ifá-Lang supports debugging via the Debug Adapter Protocol:

Debug 
# Start the debug server
ifa debug --file script.ifa

# Supports:
#   - Breakpoints
#   - Step through / step into
#   - Variable inspection
#   - Stack trace

REPL (Interactive Shell)

Start an interactive Read-Eval-Print Loop:

REPL 
# Start the REPL
ifa repl

# In the REPL:
# > Irosu.fo("Hello REPL!");
# > ayanmo x = 42
# > x * 2  # last expression is printed
# 84
# > // Use :help for commands

Bytecode Compilation

Compile to .ifab bytecode format:

Bytecode 
# Compile to .ifab bytecode
ifa bytecode script.ifa -o script.ifab

# Run bytecode (requires matching .ifa source for verification)
ifa runb script.ifab

# Bytecode format:
#   Magic bytes: "IFA\0"
#   Version: 3
#   Header: magic(4) + version(2) + sizes(9)
#   80+ opcodes (Push, Add, Call, Jump, etc.)

Documentation Generator

Doc 
# Generate HTML docs from .ifa source files
ifa doc input.ifa output-dir/

Deployment Scanner

Deploy 
# Zero-config deployment scan
ifa deploy

# Scans the current project and generates
# deployment configuration automatically

Testing

Test 
# Run all tests in the project
ifa test

# Test files match: *_test.ifa or test_*.ifa
# Use # expect: comments for expected output
