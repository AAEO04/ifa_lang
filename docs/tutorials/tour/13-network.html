Network

HTTP requests with Otura domain

Feature Gate

Otura (the Odù of communication) requires the backend feature flag in your Ifa.toml. Network requests are asynchronous and use the daro (await) keyword.

HTTP GET (gba)

Use Otura.gba() to make GET requests:

GET Request 
// Simple GET request
ayanmo response = daro Otura.gba("https://api.example.com/data");
Irosu.fo(response);

HTTP POST (ran)

Use Otura.ran() to make POST requests:

POST Request 
// POST with JSON body
ayanmo body = "{\"name\": \"Ifá\", \"type\": \"language\"}";
ayanmo response = daro Otura.ran("https://api.example.com/submit", body);
Irosu.fo(response);

Working with JSON

API Client 
isọdẹlẹ fetch_user(id) {
    ayanmo url = "https://api.example.com/users/" + id;
    ayanmo response = daro Otura.gba(url);
    Irosu.fo("Response: " + response);
}

fetch_user(42);
Note

Otura currently supports gba (GET) and ran (POST) only. PUT and DELETE are not yet implemented. All requests are async and require the daro keyword.

What You Learned
