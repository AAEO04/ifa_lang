Lists

Working with ordered collections

Creating Lists

List Creation 
// Empty list
ayanmo empty = [];

// Homogeneous list
ayanmo numbers = [1, 2, 3, 4, 5];

// Mixed types
ayanmo mixed = [1, "hello", otito, 3.14];

// Nested lists
ayanmo matrix = [[1, 2], [3, 4], [5, 6]];
// Empty list
let empty = [];

// Homogeneous list
let numbers = [1, 2, 3, 4, 5];

// Mixed types
let mixed = [1, "hello", true, 3.14];

// Nested lists
let matrix = [[1, 2], [3, 4], [5, 6]];

Accessing Elements: Ogbe

Use Ogbe.ohun() for access and Ogbe.iye_ohun() for length:

Reading from Lists 
ayanmo fruits = ["apple", "banana", "cherry"];

Ogbe.ohun(fruits, 0);        // "apple"
Ogbe.ohun(fruits, 2);        // "cherry"
Ogbe.iye_ohun(fruits);       // 3
Ogbe.ile(fruits);            // "apple" (first)
Ogbe.oju_ona(fruits);        // "cherry" (last)

// Check membership
Ogbe.ayika(fruits, "banana");  // otito (true)

Manipulating Lists: Ogunda

Use Ogunda for push, pop, and mutations:

List Operations 
ayanmo stack = [1, 2, 3];

Ogunda.fi(stack, 4);        // push → [1, 2, 3, 4]
Ogunda.fi(stack, 5);        // push → [1, 2, 3, 4, 5]

ayanmo last = Ogunda.mu(stack);  // pop → 5, stack is [1, 2, 3, 4]

Ogunda.ge(stack, 1);        // get index 1 → 2
Ogunda.wa(stack, 3);        // contains 3? → otito
Ogunda.yo(stack, 0);        // remove at index 0 → stack is [2, 3, 4]

Sorting: Ogunda.to

Sorting 
ayanmo scores = [42, 7, 99, 13, 55];
Ogunda.to(scores);
Irosu.fo(scores);  // [7, 13, 42, 55, 99]

Aggregation: Obara

Use Obara for computing over lists:

Aggregation 
ayanmo values = [10, 20, 30, 40, 50];

Obara.apapo(values);         // sum → 150
Obara.kere_julo(values);    // min → 10
Obara.nla_julo(values);     // max → 50

Iterating Lists

For Loops 
ayanmo cities = ["Ile-Ifẹ", "Ọyọ", "Abeokuta"];

fun city ninu cities {
    Irosu.fo("City: " + city);
}

// Using index with range
fun i ninu range(0, Ogbe.iye_ohun(cities)) {
    Irosu.fo(i + ": " + Ogbe.ohun(cities, i));
}
let cities = ["Ile-Ifẹ", "Ọyọ", "Abeokuta"];

for city in cities {
    Irosu.println("City: " + city);
}

// Using index with range
for i in range(0, Ogbe.iye_ohun(cities)) {
    Irosu.println(i + ": " + Ogbe.ohun(cities, i));
}
