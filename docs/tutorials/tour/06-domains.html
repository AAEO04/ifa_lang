Domains

The 16 Odù and their capabilities

Odù: The Sacred Source

In Ifá-Lang, the 16 Odù of the Ifá divination system map directly to API domains. Each Odù governs a specific area of computation, just as each Odù governs an aspect of life in Yoruba tradition.

The 16 Domains

Each domain can be referenced by its Yoruba name or its English alias in code.

Domain Alias Purpose Feature Gate
Ogbe System CLI args, environment, OS info, home/cwd, lifecycle Always
Oyeku Exit Exit codes, sleep, halt, termination Always
Iwori Time Date/time, timestamps, formatting, iteration (range) Always
Odi File Read/write/append, mkdir, list, SQLite database database
Irosu Log Print, error, input, color output, screen clear Always
Owonrin Random Random int/float/bool, shuffle, choice, UUID Always
Obara Math Sum, add, multiply, pow, sqrt, min, max Always
Okanran Error Assertions, try/catch, throw, panic, proverbs Always
Ogunda Array List/array ops (push/pop/filter/map/sort), subprocess spawn Always
Osa Flow Concurrency: async spawn, channels, actors, mutex, timeout async_runtime
Ika String Length, case, split/join, find/replace, Unicode Always
Oturupon Reduce Subtract, divide, modulo, negate, reciprocal Always
Otura Net HTTP GET and POST requests, networking network
Irete Crypto SHA256, HMAC, Base64, compression crypto
Ose UI Terminal UI, layout, draw, color, key input tui
Ofun Root Type info, capability checks, debug, permissions, reflection Always
Feature Gates

Some domains require enabling feature flags in your Ifa.toml: database (Odi), async_runtime (Osa), network (Otura), tui (Ose), crypto (Irete). All other domains are always available.

Domain Quick Reference

Ogbe (System) — System & Collections

Ogbe Methods
Ogbe.args();                 // CLI arguments
Ogbe.env("PATH");            // environment variable
Ogbe.cwd();                  // current working directory
Ogbe.bi();                   // initialize environment
Ogbe.bere();                 // version info
Ogbe.awon_ohun(items);       // list all items
Ogbe.ohun(items, 0);         // get item at index
Ogbe.iye_ohun(items);        // count (length)
Ogbe.ayika(items, val);      // contains?

Oyeku (Exit) — Exit, Sleep & Ebo

Oyeku Methods
Oyeku.jade(0);               // exit with code
Oyeku.duro();                // stop/abort execution
Oyeku.gbale();               // garbage collect / cleanup
Oyeku.sun(1);                // sleep seconds
Oyeku.sun_ms(500);           // sleep milliseconds
Oyeku.ebo("name");           // create Ebo (see lesson 14)

Iwori (Time) — Time & Range

Iwori Methods
Iwori.bayi();                // current local DateTime
Iwori.akoko();               // Unix timestamp
Iwori.odun();                // current year
Iwori.ojo_osu();             // current day
Iwori.yipo();                // iterate / loop
Iwori.pada();                // return from iteration
range(0, 10);                // numeric range (see lesson 4)

Odi (File) — File I/O

Odi Methods
Odi.si("path");              // open file handle
Odi.ka("path");              // read file
Odi.ko("path", content);     // write file
Odi.fikun("path", content);  // append file
Odi.wa("path");              // file exists?
Odi.pa();                    // close active file
Odi.pa_iwe("path");          // delete file
Odi.seda_apoti("dir");       // create directory
Odi.akojo("dir");            // list directory

Irosu (Log) — Console I/O

Irosu Methods
Irosu.fo("text");            // println
Irosu.so("text");            // print no newline
Irosu.kigbe("err");          // stderr
Irosu.gbo();                 // read input
Irosu.mo();                  // clear screen

Owonrin (Random) — Randomness

Owonrin Methods
Owonrin.pese(1, 100);        // random integer 1-100
Owonrin.boya();              // random boolean
Owonrin.yan(list);           // random choice
Owonrin.paaro(list);          // shuffle in place
Owonrin.uuid();              // generate UUID

Obara (Math) — Aggregation

Obara Methods
Obara.apapo(list);           // sum
Obara.kere_julo(list);       // min
Obara.nla_julo(list);        // max

Okanran (Error) — Error Handling

Okanran Methods
Okanran.beeni(cond, msg);    // assert true
Okanran.sise(cond, msg);     // assert condition
Okanran.dogba(a, b);         // assert equal
Okanran.yato(a, b);          // assert not equal
Okanran.ta("error");         // throw error
Okanran.gbiyanju(fn, def);   // try with fallback
Okanran.owe();               // random proverb

Ogunda (Array) — List & Map Operations

Ogunda Methods
Ogunda.fi(list, val);        // push
Ogunda.mu(list);             // pop
Ogunda.to(list);             // sort
Ogunda.pada(list);           // reverse
Ogunda.yi_pada(list, fn);    // map
Ogunda.yan(list, fn);        // filter
Ogunda.eyikeyi(list, fn);    // any?
Ogunda.gbogbo(list, fn);     // all?

Osa (Flow) — Concurrency

Osa Methods
Osa.sa(task);                // spawn async
Osa.egbe(handler);           // spawn actor
Osa.ran(actor, msg);         // send to actor
Osa.jeki();                  // yield to scheduler
Osa.titipe();                // create mutex

Ika (String) — Strings

Ika Methods
Ika.gun(s);                  // length
Ika.nla(s);                  // uppercase
Ika.kekere(s);               // lowercase
Ika.ge_lara(s, start, end);  // substring
Ika.ni(s, sub);              // contains
Ika.pin(s, delim);           // split
Ika.dapo(list, delim);       // join
Ika.ropo(s, old, new);       // replace

Oturupon (Reduce) — Math (Sub/Div)

Oturupon Methods
Oturupon.din(a, b);          // subtract
Oturupon.pin(a, b);          // divide
Oturupon.ku(a, b);           // modulo
Oturupon.dake(x);            // negate
Oturupon.idakeji(x);         // reciprocal

Otura (Net) — Networking

Otura Methods
daro Otura.gba(url);         // HTTP GET
daro Otura.ran(url, body);   // HTTP POST

Irete (Crypto) — Cryptography

Irete Methods
Irete.sha256(data);          // SHA-256 hash
Irete.sha256_hex(data);      // SHA-256 hex string
Irete.hmac_hex(key, data);   // HMAC-SHA256
Irete.base64_encode(data);   // Base64 encode
Irete.base64_decode(data);   // Base64 decode

Ose (UI) — Graphics/UI

Ose Methods
Ose.bere();                  // init terminal
Ose.pari();                  // restore terminal
Ose.ya(map);                 // draw
Ose.gboran();                // listen for keys
Ose.iwon();                  // terminal size

Ofun (Root) — Reflection

Ofun Methods
Ofun.iru(value);             // type name
Ofun.je(value, "Int");       // is type?
Ofun.le("read");             // check capability
Ofun.ju("write");            // drop capability
Ofun.afiwe(value);           // debug string

What You Learned

  • The 16 Odù map directly to API domains
  • Each domain provides specific methods for its area of computation
  • Always-available domains and feature-gated domains
  • Each domain has a canonical English alias (System, Exit, Time, etc.) that you can use interchangeably with the Yoruba name in use imports
  • Each domain has its own dedicated lesson later in this tour
