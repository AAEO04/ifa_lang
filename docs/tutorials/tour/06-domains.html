Domains

The 16 Odù and their capabilities

Odù: The Sacred Source

In Ifá-Lang, the 16 Odù of the Ifá divination system map directly to API domains. Each Odù governs a specific area of computation, just as each Odù governs an aspect of life in Yoruba tradition.

The 16 Domains

Domain Purpose Feature Gate
Ogbe Collections, iteration, counting Always
Oyeku Spirits, Ebo (rituals), transformations Always
Iwori Creation, attributes, progress, range Always
Odi File and filesystem operations backend
Irosu Input/Output (print, error, logging) Always
Owonrin Randomness, UUID, time Always
Obara Aggregations: sum, min, max on lists Always
Okanran Error handling, assertions, exceptions Always
Ogunda List/data structure operations Always
Osa Async operations, polling, timing backend
Ika String manipulation Always
Oturupon Transformations, encoding, validation Always
Otura Network: HTTP GET and POST backend
Irete Cryptography: SHA256, HMAC, Base64 crypto
Ose Game development (TUI/rendering) game
Ofun Meta-programming, reflection, type info Always
Feature Gates

Some domains require enabling feature flags in your Ifa.toml: backend (Odi, Osa, Otura), game (Ose), crypto (Irete). All other domains are always available.

Using Irosu for Output

Irosu (the Odù of light/proclamation) handles all input/output:

Irosu Methods 
Irosu.fo("Hello with newline");  // println
Irosu.so("Inline text");         // print (no newline)
Irosu.kigbe("Error!");           // eprintln (stderr)

Using Ogbe for Collections

Ogbe (the first Odù, source of existence) handles collection operations:

Ogbe Methods 
ayanmo items = [1, 2, 3, 4, 5];

Ogbe.awon_ohun(items);     // list all items
Ogbe.ohun(items, 2);       // get item at index
Ogbe.iye_ohun(items);      // count items (length)
Ogbe.ayika(items, 3);      // check if contains
Ogbe.ile(items);            // first item
Ogbe.oju_ona(items);       // last item

Using Ogunda for List Manipulation

Ogunda (the Odù of structure) modifies lists:

Ogunda Methods 
ayanmo list = [1, 2, 3];

Ogunda.fi(list, 4);         // push (append)
Ogunda.mu(list);            // pop (remove last)
Ogunda.ge(list, 1);         // get element at index
Ogunda.wa(list, 3);         // check if contains
Ogunda.yo(list, 1);         // remove at index
Ogunda.to(list);            // sort the list

Using Obara for Aggregation

Obara (the Odù of gathering) computes over lists:

Obara Methods 
ayanmo numbers = [10, 20, 30, 40, 50];

Obara.apapo(numbers);         // sum
Obara.kere_julo(numbers);    // min
Obara.nla_julo(numbers);     // max

Using Ofun for Reflection

Ofun (the Odù of completion/wisdom) provides meta-programming:

Ofun Methods 
Ofun.iru(42);            // type of value: "Int"
Ofun.iru("hello");       // "Str"
Ofun.iru([1, 2, 3]);     // "List"
Ofun.iru(greet);          // "Fn" (function reference)

What You Learned

  • The 16 Odù map directly to API domains
  • Always-available domains: Ogbe, Oyeku, Iwori, Irosu, Owonrin, Obara, Okanran, Ogunda, Ika, Oturupon, Ofun
  • Feature-gated domains: Odi (backend), Osa (backend), Otura (backend), Ose (game), Irete (crypto)
  • Real domain method names use Yoruba vocabulary
