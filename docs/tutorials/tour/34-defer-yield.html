    34. Defer & Yield

    Guaranteed cleanup and cooperative multitasking

    1. Defer — Guaranteed Cleanup

    defer / gbe schedules a block of code to run when the enclosing function returns — regardless of how it returns (normal return, throw, or early exit):

    ese read_file(path) {
    ayanmo file = Odi.si(path);
    defer { Odi.pa(file); }  // Always closes the file
    
    ti (Odi.wa(path) == false) {
        pada null;  // defer still runs
    }
    
    ayanmo content = Odi.ka(file);
    pada content;  // defer still runs
}

    Unlike finally which attaches to a try block, defer attaches to the entire function. Multiple defers run in last-in-first-out order (stack-like):

    ese multi_resource() {
    ayanmo db = connect_db();
    defer { db.close(); }
    
    ayanmo file = Odi.si("log.txt");
    defer { Odi.pa(file); }
    
    ayanmo lock = acquire_lock();
    defer { release(lock); }
    
    // Work with resources
    // When function exits: lock released, file closed, db closed
}

    2. Defer vs Ebo vs Finally

    FeatureScopeRuns OnUse Case
    deferFunctionAny exitSingle cleanup action near allocation
    ebo { }BlockBlock exitScoped memory, batches of allocations
    finally { }Try blockTry exit (success or catch)Cleanup tied to error handling

    3. Yield — Cooperative Multitasking

    jowo / yield pauses the current execution and yields control back to the scheduler for a specified duration (in milliseconds). This enables cooperative multitasking without spawning full actors:

    ese blink_led() {
    nigba (true) {
        Irosu.fo("LED ON");
        jowo 500;    // Yield for 500ms
        Irosu.fo("LED OFF");
        jowo 500;
    }
}

    During the yield, other tasks can run. The scheduler resumes this function after the specified duration.

    4. Yield in Loops

    Use yield inside long-running loops to avoid starving other tasks:

    ese process_batch(items) {
    fun (i, item) ninu Ogunda.awon_nkan(items) {
        process(item);
        
        // Yield every 100 items to keep the system responsive
        ti (i % 100 == 0) {
            jowo 10;  // 10ms breather
        }
    }
}

    5. Defer + Yield Patterns

    ese server_loop() {
    ayanmo server = Otura.de(":8080");
    defer { Otura.pa(server); }
    
    nigba (true) {
        ayanmo conn = reti Otura.gba_handle(server);
        ebo "request" {
            handle_request(conn);
        }
        jowo 1;  // Yield between requests
    }
}
