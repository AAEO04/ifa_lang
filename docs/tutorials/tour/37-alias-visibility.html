    37. Alias, AssertType & Visibility

    Type aliases, runtime type checks, and access control

    1. Alias — Type Aliases

    alias / oruko creates a type alias — a new name for an existing type. This is purely a compile-time concept; no code is generated:

    // Create type aliases
alias UserId = Int;
alias JsonString = Str;
alias Callback = fn(Int) -> Str;

// Use them in type annotations
ayanmo uid: UserId = 42;
ayanmo json: JsonString = '{"key": "value"}';

// Aliases are transparent — UserId and Int are the same type
ayanmo sum: Int = uid + 8;  // 50

    Aliases improve code readability without runtime overhead:

    // Without alias — hard to read
ese find_user(id: Int, db: Map) -> Map { ... }

// With alias — self-documenting
alias UserId = Int;
alias Database = Map;
alias UserRecord = Map;

ese find_user(id: UserId, db: Database) -> UserRecord { ... }

    2. AssertType — Runtime Type Checks

    assert_type(value, TypeName) checks at runtime that a value has the expected type. It throws if the check fails:

    ayanmo value = Ogunda.yan([1, "two", 3], random_selector);
assert_type(value, Int);  // Throws if value is not an Int

// Works with all type names
assert_type(42, Int);
assert_type(3.14, Float);
assert_type("hello", Str);
assert_type(true, Bool);
assert_type([1, 2, 3], List);
assert_type({"a": 1}, Map);

    This is useful at API boundaries where you want to validate inputs:

    ese process_config(raw) {
    assert_type(raw, Map);
    
    ayanmo port = raw["port"];
    assert_type(port, Int);
    
    ayanmo host = raw["host"];
    assert_type(host, Str);
    
    Irosu.fo($"Connecting to {host}:{port}");
}

    3. Visibility — Public and Private

    By default, all items are private — accessible only within the same module. Use gbangba / public / pub to expose them:

    // Private function — internal to this module
ese helper() {
    Irosu.fo("internal");
}

// Public function — part of the module API
gbangba ese run() {
    helper();  // Can call private items within the same module
    Irosu.fo("running");
}

// Public constant
gbangba const VERSION = "2.0.0";

    4. Visibility on Odù Methods

    Class methods also support visibility:

    odu Server {
    // Public — callable from outside
    gbangba ese start() {
        init_socket();
    }
    
    // Private — internal only
    ese init_socket() {
        Irosu.fo("Socket initialized");
    }
}
    Note: Ifá-Lang also supports ikoko / adani / private for explicit private declarations, though private is the default.
