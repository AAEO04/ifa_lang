Parallel Computing

Multi-core processing with CPU domain

CPU Domain

The CPU domain (from the hardware layer) provides parallel operations. It can be configured with CPU.configure() for thread counts and work group sizes.

CPU Information

CPU Info 
// Get number of logical cores
ayanmo cores = SYS.ìka("cores");
Irosu.fo("Cores: " + cores);  // e.g., 8

Parallel Map

CPU.par_map() applies a function to each element in parallel:

Parallel Map 
ayanmo numbers = [1, 2, 3, 4, 5, 6, 7, 8];

// Square each number in parallel
ayanmo squared = CPU.par_map({ x -> x * x }, numbers);
Irosu.fo(squared);  // [1, 4, 9, 16, 25, 36, 49, 64]

Parallel Reduce

CPU.par_reduce() combines all elements using a binary function:

Parallel Reduce 
ayanmo values = [1, 2, 3, 4, 5, 6, 7, 8];

// Sum all numbers in parallel
ayanmo sum = CPU.par_reduce({ a, b -> a + b }, values, 0);
Irosu.fo("Sum: " + sum);  // 36

// Find maximum in parallel
ayanmo max = CPU.par_reduce({ a, b -> ti (a > b) a bibẹkọ b }, values, 0);
Irosu.fo("Max: " + max);  // 8

Configuration

Configuring the CPU 
// Configure thread pool
CPU.configure("threads", 4);     // use 4 threads
CPU.configure("workgroup", 64);  // work group size
Note

Parallel operations require the parallel feature flag. Without it, par_map and par_reduce fall back to sequential execution.

Practical Example: Image Processing

Batch Processing 
ayanmo pixels = [12, 45, 78, 23, 90, 34, 56, 67];

// Brighten each pixel in parallel
