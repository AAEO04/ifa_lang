api.ifa

API Reference

Complete reference for all 16 Odu domains + 7 stacks

Methods listed with dispatch name first, followed by aliases. Source: crates/ifa-std/src/vm_registry.rs.

Core Domains (16 Odu)

Ogbe 1111

System / Lifecycle

bere (version)

Oyeku 0000

Exit / Sleep

jade (exit, quit, halt), sun (sleep, wait)

Iwori 0110

Time / Loops

bayi (now, current), akoko (timestamp)

Odi 1001

File / I/O

ka (read), ko (write), wa (exists)

Irosu 1100

Log / Console I/O

fo (println), so (print), gbo (listen), gbo_nomba, mo (clear), san (flush), kigbe (error)

Owonrin 0011

Random / Entropy

pese (random)

Obara 1000

Math / Aggregation

fikun (add, plus), isodipupo (mul, times), agbara (pow), gbongbo (sqrt)

Okanran 0001

Error / Assert

sise (assert), kigbe (throw)

Ogunda 1110

Array / Collections

iwon (len), fi (push), mu (pop), yi_pada (map), yan (filter), seku (reduce)

Osa 0111

Flow / Concurrency

ise (spawn), sun (sleep), gbogbo (all), egbe (spawn_actor), ran (send)

Ika 0100

String / Text

gigun (len), ge (slice), so (concat), oruko_html (html_title), tumo_html (strip_html)

Oturupon 0010

Reduce / Math Sub/Div

yokuro (sub, minus), pipin (div, divide)

Otura 1011

Net / HTTP

gba (get, fetch), ran (post)

Irete 1101

Crypto / Hash (requires crypto feature)

hash (sha256), hmac (hmac_sha256), base64 (base64_encode), decode (base64_decode)

Ose 1010

UI / Graphics (requires `tui` feature)

bere (init), pari (end), ya (draw), gbile (read_key), gboran (listen), ipile (layout)

Ofun 0101

Root / Permissions

le (can, eval), dbg (debug)

Infrastructure Domains

CPU (18)

Parallel processing (requires parallel feature)

configure, threads (num_threads), alloc_buffer, read_buffer, write_buffer, par_map (map), par_reduce (reduce)

GPU (19)

GPU compute (requires gpu feature)

init, dispatch_pipeline (dispatch), sync, alloc_buffer, read_buffer, write_buffer

Storage (20)

Key-value persistence (requires tokio + persistence features)

open, get, set, delete (del), compact

Sys (29)

System info

num_cores (cores), total_memory (mem_total), available_memory (mem_available), uptime

Stacks

Crypto

Production cryptography

SHA, HMAC, Argon2, AES, SecureRng

Backend

HTTP servers

serve, router, get, post, middleware

Frontend

XSS-safe HTML

html, escape, div, form, components

GameDev

Game development

Vec2, AABB, collision, sprites, ECS

ML

Machine learning

tensor, matmul, relu, softmax, conv2d

IoT

Embedded/Hardware

GPIO, Serial, I2C, SPI, sensors

Fusion

Fullstack hybrid

app, api, ui, IPC, state sync
