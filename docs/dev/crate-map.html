    Layer 1: Foundation (no_std)

    ifa-bytecode

    → crates/ifa-bytecode/Cargo.toml:2 Version 0.1.0 (standalone, not workspace) Edition 2021 (not workspace)

    The binary interface contract. Defines the OpCode enum (60+ variants), bytecode format (MAGIC, VERSION, header), and error codes. Zero dependencies (serde optional). The only crate with #![warn(missing_docs)] (lib.rs:16).

    Public: OpCode (enum), ErrorCode, InvalidOpCode, BytecodeHeader, FormatError, MAGIC, VERSION
    Features: default = ["std"], alloc, std (enables alloc + serde/std)

    ifa-types

    → crates/ifa-types/Cargo.toml:2 Version 1.3.0 (workspace)

    Shared type system: IfaValue (32-byte enum with CompactString SSO, small-int pool 0–255, NaN-boxing path), OduDomain (fixed 16 canonical Odù + 4 infrastructure + 2 reserved — not extensible, see domain.rs:14-17), IfaError/IfaResult, NanBox, IfaShared (Arc+RwLock/DashMap). Dual-path design: value_union.rs (VM path, gated by feature = "vm") vs value.rs (legacy path).

    Key public types: IfaValue, OduDomain, IfaError, IfaResult, NanBox, CompactString, IfaShared, OpCode (re-export), Statement (behind vm feature), Bytecode (behind vm feature)
    Features: default = ["std", "serde", "dashmap"], vm (enables ast + bytecode modules), std, serde, dashmap, alloc

    Layer 2: Core Runtime

    ifa-vm

    → crates/ifa-vm/Cargo.toml:2

    The primary execution engine. Contains IfaVM (vm.rs:127) with single-match opcode dispatch (vm.rs:1214), Ikin constant pool (vm_ikin.rs), Iroke instruction fetch with fuel metering (vm_iroke.rs:17), async task queue (vm.rs:948), actor system (actor.rs), and Opon memory protection (opon.rs). The largest crate.

    Internal deps: ifa-types (vm), ifa-bytecode, ifa-parser, ifa-compiler, ifa-transpiler, ifa-sandbox (optional)
    Key public types: IfaVM, Bytecode, OpCode, Compiler, compile, ProjectConfig, RustTranspiler, Opon, IwaPele, Ebo, ModuleResolver, Ajose
    Features: default = ["native", "parallel", "sysinfo"], native (enables sandbox), network (ureq), audio (rodio), parallel (rayon), gpu (wgpu), persistence, sysinfo
    Bench: opcode_dispatch (Criterion, Cargo.toml:75)

    ifa-parser

    → crates/ifa-parser/Cargo.toml:2

    Lexer via logos + parser via pest PEG grammar. Produces AST (ifa_types::ast). Re-exports OduDomain, Token, tokenize, parse.

    Internal deps: ifa-types (vm feature)

    ifa-compiler

    → crates/ifa-compiler/Cargo.toml:2

    AST → bytecode compiler. Single-file (no submodules). Key features: tail call optimization (return f(x) → TailCall, lib.rs:592), constant inlining (lib.rs:1214), string dedup via HashMap (lib.rs:127), static Odu method resolution (lib.rs:1574). No optimization passes beyond TCO and constant inlining.

    Internal deps: ifa-types, ifa-parser, ifa-bytecode

    ifa-transpiler

    → crates/ifa-transpiler/Cargo.toml:2

    Ifá-Lang → Rust source-to-source transpiler. Generates standalone Rust binaries with its own IfaValue enum embedded in the output (via statements.rs:54). Not VM-based — each transpiled program is a self-contained native binary. Used by ifa build.

    Internal deps: ifa-types, ifa-parser

    Layer 3: Standard Library & Platform Runtimes

    ifa-std

    → crates/ifa-std/Cargo.toml:2

    The 16 Odù domains standard library. These are the fixed core language domains — no new Odù can be added to OduDomain (domain.rs:14-17). Custom functionality goes through external packages imported via iba and distributed via oja (ifa-cli/src/oja.rs).

    Always-available: ogbe, oyeku, iwori, odi, irosu, owonrin, obara, okanran, ogunda, ika, oturupon, ofun. Gated: osa (async_runtime), otura (network), ose (tui), irete (crypto). Also: ffi (polyglot), infra/{cpu,gpu,storage,kernel,shaders,runtime}.

    Internal deps: ifa-types, ifa-vm (for domain registry)

    ifa-embedded

    → crates/ifa-embedded/Cargo.toml:2

    no_std runtime for microcontrollers. Target features: esp32, stm32, rp2040. Uses ifa-vm with default-features = false.

    Public: EmbeddedVM, EmbeddedConfig, MmioRegion

    ifa-wasm

    → crates/ifa-wasm/Cargo.toml:2

    WASM bindings via wasm-bindgen. Exports compile, run, format, analyze as JS-callable functions. Compiled with wasm-pack.

    → crates/ifa-babalawo/Cargo.toml:2

    → crates/ifa-sandbox/Cargo.toml:2

    Capability-based security. Defines Ofun enum (ReadFiles, WriteFiles, Network, Execute, Environment, Time, Random, Stdio, Bridge). CapabilitySet gates all domain operations in the VM and interpreter.

    ifa-installer-gui

    ifa-macros

    → crates/ifa-macros/Cargo.toml:2

    Procedural macros for domain safety (#[odu_domain]), capability gating, and bilingual keyword generation.

    ifa-infra

    → crates/ifa-infra/Cargo.toml:2

    Hardware abstraction layer. Contains cpu.rs (task parallelism, async, thread pool), gpu.rs (wgpu compute), storage.rs (high-performance I/O), kernel.rs (system calls, feature-gated by sysinfo), shaders.rs (pre-built WGSL compute shaders).

    Internal deps: ifa-types
