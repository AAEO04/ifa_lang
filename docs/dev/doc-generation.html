    What It Does

    ifa doc generates HTML documentation for Ifá-Lang projects. It walks .ifa source files, parses them using the real language parser (ifa_parser), extracts /// doc comments, and produces a static site:

    • index.html — landing page with all 20 domains + user Odù + orphans
    • <slug>.html — one page per domain (16 Odù + 4 infra) listing their methods from odu_metadata.rs
    • user_<slug>.html — one page per user-defined Odù with doc-commented items

    How Doc Extraction Works

    Unlike the old line-by-line scanner, the current parse_file() uses the real parser:

    let program = ifa_parser::parser::parse(&content)?;

for stmt in program.statements {
    let span = stmt.span();
    let docs = extract_docs_before(&content, span.start);
    // match on Statement::OduDef, EseDef, IwaDef, etc.
}

    extract_docs_before() (line 962) scans backwards from the AST node's span.start offset, collecting contiguous /// lines. This is AST-aware — it works for any construct the parser knows about, including nested protocol methods.

    Usage

    # Generate docs from src/ into docs/
ifa doc src/ --output docs/

# Generate from a single file
ifa doc src/main.ifa

    Limitations

    • No cross-references or hyperlinks between methods
    • No search functionality in generated output
    • No versioning or changelog generation
    • Method signatures show only parameter names, not types
    • No feature-gate awareness — docs show all methods regardless of #[cfg]
