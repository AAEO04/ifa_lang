    Test structure, conformance, benchmarks — source-verified

    Source-verified. Extracted from actual test files in each crate's tests/ directory, Cargo.toml dev-dependencies, and CI workflow files.

    1. Conformance Tests (ifa-cli)

    crates/ifa-cli/tests/conformance_tier1.rs (126 lines).

    Tests run the ifa binary against .ifa source files that contain a # expect: <output> comment. Three engine modes:

    ModeCommandWhat it tests
    astifa run <file>Tree-walking interpreter path
    vmifa bytecode + ifa runbBytecode compiler + VM path
    buildifa buildTranspiler → native binary path

    Test discovery: walks a directory of .ifa files, reads the # expect: header, runs the given engine, checks stdout matches.

    4. Property-Based Tests

    proptest is a dev-dependency of ifa-vm (Cargo.toml:75). The property tests in tests/proptest_tests.rs generate random bytecode sequences and verify that the VM handles them without crashing (no panics, no undefined behavior).

    5. Benchmarks

    crates/ifa-vm/benches/opcode_dispatch.rs — Criterion benchmarks.

    BenchmarkWhat it measuresOperations
    bench_arithmetic1000 sequences of PushInt, PushInt, Add, Pop~4000 opcodes including VM setup
    bench_dispatch1000 sequences of PushNull, PopPure dispatch overhead

    Not benchmarked yet: function calls, closures, collection ops, string operations, async/task overhead, Odu domain dispatch, sandbox overhead.

    Run: cargo bench -p ifa-vm
