Available Shaders

Tiled matrix multiplication with shared memory optimization.

  • Tile size: 16x16
  • Workgroup size: 16x16
  • Features: Shared memory tiling, boundary checks

Shader Design

Shaders are WGSL source strings embedded in crates/ifa-std/src/infra/shaders.rs. They use standard WGSL patterns:

  • @group(0) @binding(N) var<storage, read_write> for buffer bindings
  • @compute @workgroup_size(N) for workgroup configuration
  • workgroupBarrier() for shared memory synchronization
