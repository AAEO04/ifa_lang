gpu.ifa

GPU Infrastructure

Domain 19: Hardware Acceleration & Compute

Overview

GPU Infrastructure provides hardware acceleration via WGPU (WebGPU). Requires the gpu feature flag. Includes init, dispatch_pipeline, sync, and buffer management operations.

Source: crates/ifa-std/src/hardware/gpu.rs

Methods

init

Initialize GPU context in headless mode (no surface). Returns a GPU handle resource.

ayanmo gpu = GPU.init()

dispatch_pipeline | dispatch

Dispatch a compute pipeline by name with workgroup counts (x, y, z).

GPU.dispatch_pipeline(gpu, "matmul", 16, 16, 1)

sync

Submit and sync GPU queue operations.

GPU.sync(gpu)

alloc_buffer

Allocate a GPU storage buffer of given size (in elements).

ayanmo buf = GPU.alloc_buffer(gpu, 1024)

read_buffer

Read data from GPU into a CpuOponView buffer.

ayanmo view = GPU.read_buffer(gpu, buf)

write_buffer

Write a list of numbers into a GPU buffer.

GPU.write_buffer(gpu, buf, [1.0, 2.0, 3.0])
