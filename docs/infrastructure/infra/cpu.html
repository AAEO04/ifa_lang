cpu.ifa

CPU Infrastructure

Domain 18: The Scheduler

Overview

CPU Infrastructure provides high-performance task parallelism via Rayon thread pool. It enables buffer management and parallel data operations. Requires the parallel feature flag.

Source: crates/ifa-std/src/hardware/cpu.rs

Methods

configure

Configure the global Rayon thread pool with specified number of worker threads.

Cpu.configure(8)

threads | num_threads

Get current number of thread pool workers.

ayanmo n = Cpu.threads()

alloc_buffer

Allocate a CpuOponView buffer of given size (float32 elements).

ayanmo buf = Cpu.alloc_buffer(1024)

read_buffer

Read data from a CpuOponView buffer into a list.

ayanmo data = Cpu.read_buffer(buf)

write_buffer

Write a list of numbers into a CpuOponView buffer.

Cpu.write_buffer(buf, [1.0, 2.0, 3.0])

par_map | map

Apply a named operation (e.g., "square", "sqrt", "negate") to each element of a buffer in parallel.

ayanmo result = Cpu.par_map(buf, "square")

par_reduce | reduce

Reduce a buffer to a single value using a named operation ("sum", "min", "max").

ayanmo total = Cpu.par_reduce(buf, "sum")

CpuOponView

A resource handle wrapping an Arc<Mutex<Vec<f32>>> that holds GPU/CPU-compatible float32 buffer data.
