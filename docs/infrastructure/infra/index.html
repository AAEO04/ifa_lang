infra.ifa

Infrastructure

Low-level hardware access and system primitives

The Infrastructure layer provides direct access to hardware resources for performance-critical applications. Located in crates/ifa-std/src/hardware/. Dispatched via domain IDs 18 (CPU), 19 (GPU), 20 (Storage), 29 (Sys).

Modules

CPU

Parallel iterators (rayon), thread pool configuration, buffer management, par_map/par_reduce.

Dispatch: crates/ifa-std/src/hardware/cpu.rs

View Documentation

GPU

WGPU compute, init/dispatch_pipeline/sync, buffer management. Requires gpu feature.

Dispatch: crates/ifa-std/src/hardware/gpu.rs

View Documentation

Storage

OduStore append-only key-value database with async tokio backend. Requires tokio + persistence features.

Dispatch: crates/ifa-std/src/hardware/storage.rs

View Documentation

Kernel/Sys

System information: CPU cores, memory stats, uptime. Some functions require sysinfo feature.

Dispatch: crates/ifa-std/src/hardware/sys.rs

View Documentation

Shaders

Pre-built WGSL compute shaders for common GPU operations (matmul, reduce, relu, softmax, etc.).

Source: crates/ifa-std/src/infra/shaders.rs

View Documentation

When to Use

  • CPU: Batch processing, parallel algorithms, data parallelism
  • GPU: ML inference, image processing, physics simulations
  • Storage: Embedded databases, caching, session storage
  • Kernel: System monitoring, resource-aware scaling
  • Shaders: Custom GPU compute pipelines
