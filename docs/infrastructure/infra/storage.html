storage.ifa

Storage Infrastructure

Domain 20: Persistence Engine

Overview

Storage Infrastructure provides key-value persistence via OduStore with async tokio backend. Requires both the tokio and persistence feature flags. Returns IfaValue::Future for async operations.

Source: crates/ifa-std/src/hardware/storage.rs (bridges to crates/ifa-infra/src/storage.rs OduStore)

Methods

open

Open a storage file at the given path. Returns a Future containing a store handle (Int).

ayanmo store = Storage.open("data.ifas")

get

Get a value by key from the store. Returns a Future containing the value or null.

ayanmo val = Storage.get(store, "user:123")

set

Set a key-value pair in the store. Returns a Future.

Storage.set(store, "user:123", user_data)

delete | del

Delete a key from the store. Returns a Future.

Storage.delete(store, "user:123")

compact

Compact the append-only log to reclaim space. Returns a Future.

Storage.compact(store)

Error Handling

Storage operations return IfaValue::str("StorageError: ...") on failure or IfaValue::null() on success. KeyNotFound returns null silently.

Serialization

Values are serialized via the same bincode / IfaValueSurrogate path used by yanda deep-copy transfers. All IfaValue variants are supported — the Set type included. Variants without a serializable representation (Fn, Closure, Actor, Future) are rejected at store time with a clear error.

See Yanda documentation for details on the serialization bridge.
