kernel.ifa

Kernel / Sys Infrastructure

System calls and hardware information. Domain ID 29.

Source: crates/ifa-std/src/hardware/sys.rs

Feature Flag: sysinfo (for memory/uptime functions)

Core Functions

num_cores | cores -> Int

Get number of logical CPU cores. Always available, no feature flag required.

ayanmo cores = Sys.num_cores()
Irosu.fo("CPU cores: " + cores)

System Info (requires sysinfo feature)

uptime -> Int

Get system uptime in seconds.

ayanmo uptime = Sys.uptime()

total_memory | mem_total -> Int

Get total system memory in bytes (cached for performance).

ayanmo total = Sys.total_memory()

available_memory | mem_available -> Int

Get available system memory in bytes (refreshes on each call).

ayanmo available = Sys.available_memory()

Use Cases

Resource-Aware Scaling

ayanmo cores = Sys.num_cores()
ayanmo batch_size = cores * 1000

System Monitoring

ayanmo total = Sys.total_memory()
ayanmo available = Sys.available_memory()
ayanmo percent = ((total - available) * 100) / total
Irosu.fo("Memory usage: " + percent + "%")
