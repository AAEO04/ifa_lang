Syntax Reference

Complete Grammar and Language Structure

Program Structure

An Ifa-Lang program is a sequence of statements, from top to bottom execution. The 16 Odu domains (Ogbe, Irosu, Obara, etc.) are built-in and globally available without imports.

Basic Program 
// Variables
ayanmo name = "Ifa-Lang";

// Constants
const PI = 3.14159;
ayanfe VERSION = 1;

// Functions
ese greet(who) {
    Irosu.fo("Kaabo, " + who + "!");
}

// Main execution
greet("World");

Statements

Variable Declaration

Variables 
// Yoruba keywords
ayanmo x = 5;                    // Mutable variable
ayanfe VERSION = 1;              // Constant (Yoruba)
ayanmo age: Int = 25;            // With type hint

// English keywords
let x = 5;                       // Mutable variable
const NAME = "Ifa";              // Constant (English)

// With type hints
let name: Str = "Alice";
let count: i64 = 100;

Note: ayanfe/ayanfe is the Yoruba keyword for constants. English const is also valid. Constant values must be known at compile time.

Assignment

Assignments 
x = 10;                         // Simple assignment
arr[0] = 30;                     // Index assignment

// Update operators
x += 5;
x -= 1;
x *= 2;
x /= 3;
x %= 4;

Function Definition

Functions 
// Yoruba
ese add(a, b) {
    pada a + b;
}

// English
fn add(a, b) {
    return a + b;
}

// Public function (gbangba / pub / gbangba / fi / export)
gbangba ese calculate(x) {
    // Accessible from other modules
}

fi ese public_helper(x) {
    // Also public
}

// Async function
daro ese fetch_data() {
    Irosu.fo("Fetching...");
}

// Function with type hints
ese divide(a: Int, b: Int) {
    Oturupon.pipin(a, b);
}

Control Flow

If Statement

Conditional Logic 
// Yoruba
ti x > 0 {
    Irosu.fo("Positive");
} bibekọ ti x == 0 {
    Irosu.fo("Zero");
} bibekọ {
    Irosu.fo("Negative");
}

// English
if x > 0 {
    Irosu.fo("Positive");
} else if x == 0 {
    Irosu.fo("Zero");
} else {
    Irosu.fo("Negative");
}

Loops

Iteration 
// While loop (Yoruba: nigba)
nigba x < 10 {
    Irosu.fo(x);
    x = x + 1;
}

// For loop - iterates over list items
fun i ninu items {
    Irosu.fo(i);
}

// English equivalents
while x < 10 {
    Irosu.fo(x);
    x = x + 1;
}

for i in items {
    Irosu.fo(i);
}

// Break and Continue
da;              // Yoruba: break
tesiwaju;        // Yoruba: continue
break;
continue;

Note: The for loop iterates over list values only. There is no range (0..10) syntax for for-loop expressions; use while for counter-based iteration.

Match Statement

Status: The grammar includes a match_stmt rule with literal, range, and wildcard patterns. Implementation in the VM is partial; basic literal matching is functional.

Pattern Matching 
// Yoruba: yàn
yan (x) {
    0 => Irosu.fo("Zero"),
    1, 2 => Irosu.fo("Small"),
    _ => Irosu.fo("Other")
}

// English: match
match (x) {
    200 => Irosu.fo("OK"),
    404 => Irosu.fo("Not Found"),
    _ => Irosu.fo("Unknown")
}

Error Handling

Try-Catch-Finally

Exception Handling 
// Yoruba
gbiyanju {
    risky_operation();
} gba (error) {
    Irosu.fo("Error: " + error);
} nipari {
    cleanup();
}

// English
try {
    risky_operation();
} catch (error) {
    Irosu.fo("Error: " + error);
} finally {
    cleanup();
}

Assertions

Debug Assertions 
// Yoruba
ewo x >= 0, "x must be non-negative";
ewo balance >= 0;

// English
assert x >= 0, "x must be non-negative";
verify balance >= 0;

// Type assertion
assert_type(value, Int);
assert_type(result, Str);

// Okanran (explicit throw)
Okanran.kigbe("Something went wrong");

Imports and Modules

When You Need Imports

NOTE: The 16 Odu domains (Ogbe, Irosu, Obara, etc.) are built-in and do NOT need imports. They're fundamental language primitives.

Import Statements

Use imports for external packages, libraries, and application stacks (crypto, ml, gamedev, backend, frontend, iot, video):

Module Imports 
// Import external utilities
iba std.utils;
import std.utils;

// Import specific functions
iba { yokuro, pipin } from std.oturupon;

// Import from sub-modules
iba std.crypto.sha256;
import std.crypto.sha256;

Type Aliases

Create shorthand names for types:

Alias Declarations 
// Create a type alias
alias Handle = Iwa<Resource>;

// Use the alias
ayanmo conn: Handle = open_connection();

What DOESN'T Need Imports

Built-in Domains (No Imports) 
// These are WRONG - don't import the 16 Odu domains!
// iba std.irosu;    // NO! Irosu is built-in
// iba std.obara;    // NO! Obara is built-in  

// These are CORRECT - use domains directly
ese main() {
    Irosu.fo("Hello");                    // Built-in, no import needed
    ayanmo sum = Obara.fikun(1, 2);      // Built-in, no import needed
    Oyeku.jade(0);                       // Built-in, no import needed
}

Domain Calls

Call methods on the 16 Odu domains - NO IMPORTS NEEDED:

Domain Operations 
// The 16 Odu domains are built-in and globally available

// Console I/O (Irosu)
Irosu.fo("Hello, World!");          // println
Irosu.so("Enter name: ");           // print
ayanmo input = Irosu.gbo();         // read line
Irosu.mo();                         // clear
Irosu.kigbe("Error!");              // stderr

// Mathematics (Obara)
Obara.fikun(10, 20);                // add
Obara.isodipupo(3, 4);              // mul
Obara.agbara(2, 8);                 // pow
Obara.gbongbo(16);                  // sqrt

// Oturupon (inverse math)
Oturupon.yokuro(20, 10);            // sub
Oturupon.pipin(10, 3);              // div

// Cryptography (Irete, needs 'crypto' feature)
Irete.hash("data");                 // sha256
Irete.hmac("key", "data");         // hmac_sha256
Irete.base64("data");               // base64_encode
Irete.decode("ZGF0YQ==");          // base64_decode

// Time operations (Iwori)
Iwori.bayi();                       // now
Iwori.akoko();                      // timestamp

// Random (Owonrin)
Owonrin.pese();                     // random number

// System operations (Ogbe)
Ogbe.bere();                        // version

// File operations (Odi)
Odi.ka("file.txt");                 // read
Odi.ko("file.txt", "content");      // write
Odi.wa("file.txt");                 // exists

// Exit (Oyeku)
Oyeku.jade(0);                      // exit code 0
Oyeku.sun(1000);                    // sleep ms

// List ops (Ogunda)
Ogunda.iwon(list);                  // len
Ogunda.fi(list, 42);                // push
Ogunda.mu(list);                    // pop
Ogunda.yi_pada(list, fn);           // map
Ogunda.yan(list, fn);               // filter
Ogunda.seku(list, fn, 0);           // reduce

// String ops (Ika)
Ika.gigun("hello");                 // len
Ika.ge("hello", 0, 2);              // slice
Ika.so("hello", " world");          // concat

// Assertions (Okanran)
Okanran.sise(x > 0);                // assert
Okanran.kigbe("error!");            // throw/panic

// Meta (Ofun)
Ofun.le("1 + 2");                   // eval
Ofun.dbg(value);                    // debug print

// Concurrency (Osa, needs 'sync' feature)
Osa.sun(100);                       // sleep
Osa.gbogbo(tasks);                  // all/join

// Networking (Otura, needs 'backend' feature)
Otura.gba("https://example.com");   // HTTP GET
Otura.ran("https://api.com", body); // HTTP POST

// Graphics/TUI (Ose, needs 'game' feature)
Ose.bere();                         // init
Ose.ya(x, y, "text");              // draw
Ose.pari();                         // end
Ose.gbile();                        // read_key

Memory Management

Opon Directives

Memory Configuration 
// Memory size directives
#opon kekere;              // Small (256 slots, 64 frames)
#opon arinrin;             // Medium (4096 slots, 512 frames)
#opon nla;                 // Large (65536 slots, 4096 frames)
#opon ailopin;             // Unlimited

// Opon directive also accepts colon syntax
opon: arinrin;
mem: nla;

Resource Management (Ebo and Defer)

Resource Scopes 
// Ebo (offering): creates a scoped memory epoch
ebo "server_config.json";

// Ebo with body: allocs released at scope exit
ebo "region" {
    // Allocations here are released on block exit
    ayanmo data = Odi.ka("config.txt");
    // Process data...
}

// Defer: schedule cleanup at scope exit
defer {
    Irosu.fo("Cleaning up...");
}

Strict Mode

The abo directive enables strict mode — the Babalawo enforces additional static checks including type annotations on all variables and function parameters:

Strict Mode 
abo;                    // Enable strict mode

// Strict mode requires explicit type hints:
ayanmo x: Int = 5;      // OK
// ayanmo y = 5;        // ERROR: missing type hint in strict mode

Closures (Lambda Expressions)

Anonymous functions use the ese/fn keyword with parentheses for parameters:

Lambda/Closure Syntax 
// Yoruba: ese(params) { body }
ayanmo double = ese(x) { pada x * 2; };

// English: fn(params) { body }
let transform = fn(x) { return x * 2; };

// Used with Ogunda collection methods
ayanmo result = Ogunda.yi_pada(items, ese(x) { pada x + 1; });

// Filter and reduce
ayanmo evens = Ogunda.yan(items, ese(x) { pada x % 2 == 0; });
ayanmo sum = Ogunda.seku(items, ese(acc, x) { pada acc + x; }, 0);

Odu (Class) Definition

Class-like Struct 
// Yoruba: odu
odu Server {
    ayanmo port = 8080;
    ese start() {
        Irosu.fo("Server starting...");
    }
}

// English: class
class Counter {
    let count = 0;
    fn increment() {
        count = count + 1;
    }
}

Type System

Basic Types

Primitive Types 
// Numbers
ayanmo i: Int = 42;
ayanmo f: Float = 3.14;

// Text
ayanmo s: Str = "Hello";

// Boolean
ayanmo b: Bool = otito;     // true
ayanmo b2: Bool = iro;       // false

// Null
ayanmo n = ofo;              // null / nil

// Collections
ayanmo list = [1, 2, 3];
ayanmo map = {"a": 1, "b": 2};
ayanmo set = Set {1, 2, 3};           // Set literal (unique, unordered)

// Low-level types (in unsafe contexts)
ayanmo addr: u64 = 0xdeadbeef;
ayanmo byte: u8 = 255;

Type Hints on Functions

Type Annotations 
// Function parameters with type hints
ese add(a: Int, b: Int) {
    pada a + b;
}

// Variable with type hint
ayanmo name: Str = "Alice";

// Nested types (type hints only, no generics syntax)
ayanmo matrix = [[1.0, 2.0], [3.0, 4.0]];

Taboo Declarations

Declare architectural constraints between domains:

Taboo Rules 
// Yoruba
eewo: Ose -> Odi;

// English
taboo: Otura -> Irete;

Taboo declarations prevent certain domain combinations. The Babalawo static analyzer validates these constraints.

String Features

String Operations 
// Concatenation
ayanmo s = "Hello " + "World";

// Interpolated strings
ayanmo name = "Ifa";
ayanmo greeting = $"Kaabo, {name}!";  // "Kaabo, Ifa!"

// String methods via Ika
Ika.gigun("hello");                    // 5 (length)
Ika.ge("hello", 1, 3);                // "el" (slice)
Ika.oruko_html("
Title
");     // "Title" (HTML title extraction)
Ika.tumo_html("text");         // "text" (strip HTML)
