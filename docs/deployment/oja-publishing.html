Publishing to Oja

Package Publishing Guide

Overview

Publishing packages to Oja (the Ifa-Lang package registry) is done through the ifa oja publish command. Packages use ifa.toml for metadata and dependencies.

Publishing Commands

Publishing workflow 
# Validate package
ifa oja build

# Run tests
ifa oja test

# Publish to registry
ifa oja publish

Command Reference

All Oja commands available (from crates/ifa-cli/src/main.rs):

CommandDescription
init <name>Initialize new project
add <url>Add dependency
remove <name>Remove dependency
buildBuild project
run [args]Run project
testRun project tests
search <query>Search registry
publishPublish to registry
auditAudit vulnerabilities
