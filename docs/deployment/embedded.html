Embedded Deployment

Ifa-Lang on Microcontrollers and IoT Devices

Overview

Ifa-Lang Embedded (ifa-embedded) provides a no_std runtime for microcontrollers and IoT devices with memory constraints. It uses ifa-vm with default-features = false and heapless bounded collections. Two tiers: Tier 0 (no_std, no_alloc, stack-only) and Tier 1 (IoT, enables heap allocation).

Source: crates/ifa-embedded/

Supported Targets

  • esp32 — Espressif ESP32
  • stm32 — STM32 Cortex-M series
  • rp2040 — Raspberry Pi RP2040
Build for embedded target 
# Build for ESP32
cargo build --features esp32

# Build for STM32
cargo build --features stm32

# Build for RP2040
cargo build --features rp2040

Cargo.toml

Embedded Project Configuration 
[dependencies]
ifa-vm = { path = "../ifa-vm", default-features = false }
heapless = "0.8"
critical-section = "1.1"

[features]
default = []
alloc = []        # Tier 1: heap allocation
iot = ["alloc", "serde", "serde_json", "log"]
storage = ["alloc", "bincode", "serde"]
esp32 = []
stm32 = []
rp2040 = []

Memory Model

Bounded collections via heapless:

  • heapless::Vec<T, N> — Fixed-capacity vector
  • heapless::String<N> — Fixed-capacity string
  • No heap allocation in Tier 0
  • Static memory pools in Tier 1 with alloc feature

Opon Memory System

Embedded uses Opon::embedded() for smaller history:

let mut opon = Opon::embedded();
opon.record("Irosu", "fo", &IfaValue::str("Hello"));

// History has bounded size on embedded
let history = opon.get_history();
