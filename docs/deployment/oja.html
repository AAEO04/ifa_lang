oja.ifa

Oja Package Manager

Ifa-Lang Package Ecosystem

Overview

Oja (marketplace) is the package manager built into the ifa CLI. Access it via ifa oja <command>. It provides package discovery, publishing, dependency management, and auditing.

Source: crates/ifa-cli/src/main.rs (oja subcommand)

Commands

ifa oja commands 
ifa oja init          # Initialize new project
ifa oja add <url>     # Add dependency
ifa oja remove <name> # Remove dependency
ifa oja build         # Build project
ifa oja run [args]    # Run project
ifa oja test          # Run project tests
ifa oja search <q>    # Search registry
ifa oja publish       # Publish to registry
ifa oja audit         # Audit vulnerabilities
ifa oja upgrade       # Upgrade ifa CLI

Project Manifest

Oja uses ifa.toml for project configuration (see crates/ifa-cli/src/main.rs).
