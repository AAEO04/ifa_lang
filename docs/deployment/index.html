Deployment

Multi-Platform Runtime Architecture

Ifa-Lang supports multiple deployment targets through a unified codebase with platform-specific optimizations. The compilation pipeline (parser, compiler, bytecode VM) adapts to different environments while maintaining language consistency.

Native (ifa-cli)

Full-featured runtime with complete 16 Odu domains and development tools.

  • Complete standard library
  • Bytecode VM with IfaVM
  • Full development tools (REPL, LSP, debugger)
  • Multi-threading via rayon/tokio
Learn More

WebAssembly (ifa-wasm)

Browser runtime with wasm-bindgen bindings for web applications.

  • Core domains via wasm
  • Browser sandboxing
  • WebGPU support via wgpu
  • Async support
Learn More

Embedded (ifa-embedded)

no_std runtime for microcontrollers with heapless bounded collections.

  • ifa-vm with default-features=false
  • heapless bounded collections
  • Targets: esp32, stm32, rp2040
  • Tier 0 (no_std, stack-only) or Tier 1 (alloc)
Learn More

Sandbox (ifa-sandbox)

Capability-based security for safe execution of untrusted code.

  • Ofun capability enumeration
  • CapabilitySet passed to interpreter/VM
  • OmniBox WASM isolation
  • Resource monitoring
Learn More
