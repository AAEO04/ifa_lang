Ogbe Domain Examples

Version and System Foundation (1111)

Overview

Ogbe (1111) is the foundational domain providing version queries for the runtime. It exposes a single method bere (or version) that returns the current Ifá-Lang version string.

Domain Characteristics

  • Binary Pattern: 1111 (all ones - completeness)
  • Yoruba Meaning: "He who creates the path"
  • System Role: Version and runtime identification
  • Element: Fire/Air (creation and expansion)

Available Methods

  • bere | version — returns version string

Version Query

Getting the Runtime Version 
// Print the Ifá-Lang version
ayanmo ver = Ogbe.bere();
Irosu.fo("Ifá-Lang version: " + ver);

// Using the English alias
ayanmo ver2 = Ogbe.version();
Irosu.fo("Version (alt): " + ver2);

Version Check

Version Validation 
// Check minimum version requirement
ese check_min_version(min_version: Str) -> Bool {
    ayanmo current = Ogbe.version();
    Irosu.fo("Current: " + current + ", required: " + min_version);
    // Simple prefix check
    ti (Ika.len(current) >= Ika.len(min_version)) {
        ayanmo prefix = Ika.ge(current, 0, Ika.len(min_version));
        ti (prefix == min_version) {
            Irosu.fo("Version requirement met");
            pada otito;
        }
    }
    Irosu.fo("Version requirement NOT met");
    pada iro;
}

check_min_version("1.0");
