Obara Domain Examples

Arithmetic Operations (1000)

Overview

Obara (1000) provides basic arithmetic: addition, multiplication, exponentiation, and square root.

Domain Characteristics

  • Binary Pattern: 1000 (addition and accumulation)
  • Yoruba Meaning: "The accumulator"
  • System Role: Arithmetic operations
  • Element: Earth

Available Methods

  • fikun | add | plus — add two numbers
  • isodipupo | mul | times — multiply two numbers
  • agbara | pow — exponentiation
  • gbongbo | sqrt — square root

Basic Arithmetic

Addition and Multiplication 
// Addition
ayanmo a = 10;
ayanmo b = 25;
ayanmo sum = Obara.fikun(a, b);
Irosu.fo("Sum: " + sum);

// Chain addition
ayanmo total = 0;
fun num ninu [1, 2, 3, 4, 5] {
    total = Obara.fikun(total, num);
}
Irosu.fo("Total: " + total);

// Multiplication
ayanmo product = Obara.isodipupo(6, 7);
Irosu.fo("Product: " + product);

// Factorial
ayanmo fact = 1;
fun i ninu 1..6 {
    fact = Obara.isodipupo(fact, i);
}
Irosu.fo("5! = " + fact);

Exponentiation and Roots

Power and Square Root 
// Exponentiation
ayanmo power = Obara.agbara(2, 8);
Irosu.fo("2^8 = " + power);

// Square root
ayanmo root = Obara.gbongbo(144);
Irosu.fo("sqrt(144) = " + root);

// Compound growth
ayanmo principal = 1000.0;
ayanmo rate = 1.05;
ayanmo years = 2;
ayanmo amount = Obara.isodipupo(principal, Obara.agbara(rate, years));
Irosu.fo("$1000 at 5% for 2 years: $" + amount);

Practical Examples

    ayanmo height_sq = Obara.isodipupo(height_m, height_m);
