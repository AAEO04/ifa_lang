    Simple Terminal Game

    TUI Game with Ifá-Lang's Ose Domain

    Overview

    A simple terminal-based game using the Ose domain (requires `game` feature) for TUI operations: init, draw, listen for input, layout. Combined with Owonrin for random elements, Oyeku for timing, and Irosu for console output.

    Domains Used

    • Ose - bere (init), ya (draw), gboran (listen), gbile (read_key), ipile (layout), iwọn (size), duro (wait), pari (end)
    • Owonrin - pese (random)
    • Oyeku - sun (sleep)
    • Irosu - fo, kigbe

    Number Guessing Game

    Guess the Number 
    fn guess_game() {
    Ose.bere("Number Guessing Game");
    ayanmo target = Owonrin.pese(100) + 1;
    ayanmo attempts = 0;
    ayanmo playing = otito;

    Ose.ya("I'm thinking of a number 1-100");

    nigba (playing) {
        ayanmo guess = Irosu.gbo_nomba("Your guess: ");
        attempts = attempts + 1;

        ti (guess == target) {
            Ose.ya("Correct! You got it in " + attempts + " tries");
            playing = iro;
        } bibẹkọ ti (guess < target) {
            Ose.ya("Too low! Try again");
        } bibẹkọ {
            Ose.ya("Too high! Try again");
        }
    }

    Ose.pari();
    Irosu.fo("Thanks for playing!");
}

guess_game();

    Reaction Game

    Reaction Timer 
    fn reaction_game() {
    Ose.bere("Reaction Timer");

    // Wait random time, then signal
    ayanmo delay = Owonrin.pese(3000) + 1000;
    Oyeku.sun(delay);

    Ose.ya("PRESS ANY KEY NOW!");

    // Read key press
    ayanmo key = Ose.gbile();
    Ose.ya("You pressed: " + key);

    Oyeku.sun(1000);
    Ose.pari();
}

reaction_game();

    fn layout_demo() {
    Ose.bere("Layout Demo");

    // Get terminal size
    ayanmo sz = Ose.iwọn();
    Ose.ya("Terminal: " + sz.width + "x" + sz.height);

    // Listen for mouse events
    Ose.ẹmí();

    nigba (otito) {
        ayanmo event = Ose.gboran();
        ti (event == "q" or event == "quit") { da; }
        ti (Ika.gigun(event) > 0) {
            Ose.ya("Event: " + event);
        }
    }

    Ose.pari_ẹmí();
    Ose.pari();
}
