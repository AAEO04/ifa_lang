    Simple Terminal Game

    TUI Game with Ifá-Lang's Ose Domain

    Overview

    A simple terminal-based game using the Ose domain (requires `game` feature) for TUI operations: init, draw, listen for input, layout. Combined with Owonrin for random elements, Oyeku for timing, and Irosu for console output.

    Domains Used

    • Ose - bere (init), ya (draw), gboran (listen), gbile (read_key), ipile (layout), iwọn (size), duro (wait), pari (end)
    • Owonrin - pese (random)
    • Oyeku - sun (sleep)
    • Irosu - fo, kigbe

    Number Guessing Game

    Guess the Number 
    ese guess_game() {
    ayanmo tty = Ose.bere();
    ayanmo target = Owonrin.pese(1, 100);
    ayanmo attempts = 0;
    ayanmo playing = otito;

    Ose.ya(tty, {"type": "ipinro", "text": "I'm thinking of a number 1-100"});

    nigba (playing) {
        ayanmo guess = Irosu.gbo_nomba("Your guess: ");
        attempts = attempts + 1;

        ti (guess == target) {
            Ose.ya(tty, {"type": "ipinro", "text": "Correct! You got it in " + attempts + " tries"});
            playing = iro;
        } bibẹkọ ti (guess < target) {
            Ose.ya(tty, {"type": "ipinro", "text": "Too low! Try again"});
        } bibẹkọ {
            Ose.ya(tty, {"type": "ipinro", "text": "Too high! Try again"});
        }
    }

    Ose.pari();
    Irosu.fo("Thanks for playing!");
}

    Reaction Game

    Reaction Timer 
    ese reaction_game() {
    ayanmo tty = Ose.bere();

    // Wait random time, then signal
    ayanmo delay = Owonrin.pese(1000, 4000);
    Oyeku.sun(delay);

    Ose.ya(tty, {"type": "ipinro", "text": "PRESS ANY KEY NOW!"});

    // Read key press
    ayanmo key = Ose.gbile();
    Ose.ya(tty, {"type": "ipinro", "text": "You pressed: " + key});

    Oyeku.sun(1000);
    Ose.pari();
}
