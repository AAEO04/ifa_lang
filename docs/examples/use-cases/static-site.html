    Static Site Generator

    Build a static site generator using Ifa-Lang's Odi file I/O, Ogunda list operations, and Ika string processing.

    Overview

    This example demonstrates using Odi for file operations, Ika for string/template processing, Ogunda for list mapping, and Irosu for build logging.

    Domains Used

    • Odi - Read markdown files, write HTML output
    • Ika - String operations, HTML title/strip helpers
    • Ogunda - Map over file list, filter templates
    • Irosu - Build logging

    Code Example

    // Static Site Generator
ese build_site() {
    ayanmo template = Odi.ka("template.html");
    ayanmo files = ["posts/hello.md", "posts/world.md", "about.md"];

    ese process_file(path) {
        ayanmo content = Odi.ka(path);
        ayanmo title = Ika.oruko_html(content);
        ayanmo body = Ika.tumo_html(content);
        ayanmo page = template + "\n" + "
    " + title + "
    \n" + body;
        ayanmo out_name = path + ".html";
        Odi.ko("public/" + out_name, page);
        Irosu.fo("Built: " + out_name);
    }

    Ogunda.yi_pada(files, process_file);
    Irosu.fo("Site generated!");
}
