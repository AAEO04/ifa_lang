    File Processor

    File Processing with Ifá-Lang's Odi Domain

    Overview

    File processing system using Ifá-Lang's Odi domain for reading, writing, and checking files. Combined with Ika for string operations and Ogunda for batch processing.

    Domains Used

    • Odi - File read/write/exists
    • Ika - String length, slice, concat, HTML helpers
    • Ogunda - List iteration, map, filter
    • Irosu - Process logging

    Read / Check / Write Files

    Basic File Operations 
    ese process_file(path) {
    ti (Odi.wa(path)) {
        ayanmo content = Odi.ka(path);
        ayanmo length = Ika.gigun(content);

        // Convert to title case using Ika HTML helpers
        ayanmo title = Ika.oruko_html(content);
        ayanmo body = Ika.tumo_html(content);

        ayanmo output = "
    \n  
    " + title + "
    \n  " + body + "\n
    ";
        Odi.ko("out/" + path, output);
        Irosu.fo("Processed: " + path + " (" + length + " chars)");
    } bibẹkọ {
        Irosu.kigbe("File not found: " + path);
    }
}

    Batch Processing with Ogunda

    Batch File Operations 
    ese batch_process(paths) {
    ayanmo total = Ogunda.iwọn(paths);
    Irosu.fo("Processing " + total + " files");

    ese process_one(p) {
        process_file(p);
        pada p;
    }

    ayanmo results = Ogunda.yi_pada(paths, process_one);
    Irosu.fo("Completed: " + Ogunda.iwọn(results) + " files");
}

// Usage
ayanmo files = ["readme.txt", "notes.txt", "draft.txt"];
batch_process(files);

    Filter Existing Files 
    ese filter_existing(paths) {
    ese exists(p) {
        ti (Odi.wa(p)) { pada p; } bibẹkọ { pada ofifo; }
    }
    pada Ogunda.yan(paths, exists);
}

ayanmo candidates = ["a.txt", "b.txt", "c.txt"];
ayanmo existing = filter_existing(candidates);
Irosu.fo("Existing files: " + Ogunda.iwọn(existing));
