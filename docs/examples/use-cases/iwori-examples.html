Iwori Domain Examples

Time Operations and Timestamps (0001)

Overview

Iwori (0001) provides timestamp and current datetime operations. It has two methods: bayi/now/current for the current datetime and akoko/timestamp for Unix epoch timestamps.

Domain Characteristics

  • Binary Pattern: 0001 (timing and beginning)
  • Yoruba Meaning: "The watcher" or "The timekeeper"
  • System Role: Time operations
  • Element: Air

Available Methods

  • bayi | now | current — get datetime
  • akoko | timestamp — get Unix timestamp

Timestamps

Getting Current Time 
// Get current timestamp (milliseconds since epoch)
ayanmo ts = Iwori.akoko();
Irosu.fo("Unix timestamp: " + ts);

// Get current datetime
ayanmo dt = Iwori.isisinyi();
Irosu.fo("Current datetime: " + dt);

Timed Operations

Measuring Elapsed Time 
// Measure elapsed time with Oyeku.sun
ayanmo start = Iwori.timestamp();

Irosu.fo("Waiting 1 second...");
Oyeku.sun(1000);

ayanmo elapsed = Iwori.timestamp() - start;
Irosu.fo("Elapsed: " + elapsed + "ms");

Simple Timer

Countdown Timer 
// Countdown timer using Iwori + Oyeku
ese countdown(seconds) {
    ayanmo end = Iwori.timestamp() + (seconds * 1000);

    nigba (Iwori.timestamp() < end) {
        ayanmo remaining = (end - Iwori.timestamp()) / 1000;
        Irosu.fo("T-minus " + remaining + "...");
        Oyeku.sun(1000);
    }

    Irosu.fo("Done!");
}

countdown(3);
