Oturupon Domain Examples

Subtraction and division operations.

Overview

Oturupon provides subtraction (yokuro/sub/minus) and division (pipin/div/divide).

Available Methods

  • yokuro | sub | minus — subtract two numbers
  • pipin | div | divide — divide two numbers

Subtraction Examples

Basic Subtraction 
// Basic subtraction
ayanmo diff = Oturupon.din(100, 37);
Irosu.fo("100 - 37 = " + diff);

// Chain subtraction
ayanmo remaining = 100;
ayanmo expenses = [25, 15, 40];
fun e ninu expenses {
    remaining = Oturupon.din(remaining, e);
}
Irosu.fo("Remaining after expenses: " + remaining);

Division Examples

Basic Division

ayanmo scores = [85, 92, 78, 95];

Practical Example: Split Bill

Bill Splitter 
// Split a restaurant bill
ese split_bill(total, people, tip_percent) {
    ayanmo tip = Oturupon.pin(Obara.isodipupo(total, tip_percent), 100);
    ayanmo grand_total = Obara.fikun(total, tip);
    ayanmo per_person = Oturupon.pin(grand_total, people);
    pada per_person;
}

ayanmo each = split_bill(120.00, 4, 15);
Irosu.fo("Each person pays: $" + each);
