Ika Domain Examples

String Operations (1010)

Overview

Ika (1010) provides string operations: length, slicing, concatenation, and HTML utilities.

Domain Characteristics

  • Binary Pattern: 1010 (knowledge and communication)
  • Yoruba Meaning: "The seeker"
  • System Role: String operations
  • Element: Air

Available Methods

  • gigun | len — string length
  • ge | slice — slice string (string, start, end)
  • so | concat — concatenate strings
  • oruko_html | html_title — extract HTML title
  • tumo_html | strip_html — strip HTML tags

Basic String Operations

Length and Concatenation

Length and Concat 
// String length
ayanmo text = "Ifá-Lang";
ayanmo length = Ika.gigun(text);
Irosu.fo("Length: " + length);

// Concatenation
ayanmo greeting = Ika.so("Hello, ", "world!");
Irosu.fo(greeting);

// Chain concatenation
ayanmo full = Ika.so(Ika.so("A", "B"), "C");
Irosu.fo(full);

String Slicing

Slice 
// Extract substring by start/end indices
ayanmo msg = "Ifá-Lang is powerful";
ayanmo sub = Ika.ge(msg, 0, 8);
Irosu.fo("Substring: " + sub);

// Get first 3 chars
ayanmo prefix = Ika.ge(msg, 0, 3);
Irosu.fo("Prefix: " + prefix);

// Get chars from index 4 onward
ayanmo suffix = Ika.ge(msg, 4, Ika.len(msg));
Irosu.fo("Suffix: " + suffix);

Practical Text Processing

String Utilities 
// Build a string from parts
ese join_strings(parts, separator) {
    ayanmo result = "";
    ayanmo first = otito;
    fun p ninu parts {
        ti (first) {
            result = Ika.so(result, p);
            first = iro;
        } bibẹkọ {
            result = Ika.so(Ika.so(result, separator), p);
        }
    }
    pada result;
}

// Truncate text to max length
ese truncate(text, max_len) {
    ti (Ika.len(text) <= max_len) {
        pada text;
    }
    pada Ika.so(Ika.ge(text, 0, max_len - 3), "...");
}

// Example usage
ayanmo parts = ["apple", "banana", "cherry"];
ayanmo csv = join_strings(parts, ", ");
Irosu.fo("CSV: " + csv);

ayanmo long_text = "This is a very long string that should be truncated";
ayanmo short = truncate(long_text, 20);
Irosu.fo("Truncated: " + short);
