    CLI Tool

    Command-Line Interface with Ifá-Lang

    Overview

    Build a CLI tool using Irosu for console I/O (print, read input, error), Odi for config/file operations, Oyeku for exit/sleep, and Osa for spawning background tasks.

    Domains Used

    • Irosu - fo (println), gbo (read input), kigbe (error), mo (clear), gbo_nomba (read number)
    • Odi - ka (read file), ko (write file), wa (exists)
    • Oyeku - jade (exit), sun (sleep)
    • Osa - ise (spawn) for background tasks
    • Ika - gigun (len), ge (slice)

    Interactive CLI

    Main Loop 
    ese show_help() {
    Irosu.fo("Commands: greet <name>, save <file>, count <file>, exit");
}

ese main() {
    Irosu.fo("Ifá-Lang CLI v1.0");
    show_help();

    nigba (otito) {
        ayanmo input = Irosu.gbo("> ");

        ti (input == "exit" or input == "quit") {
            Irosu.fo("Goodbye!");
            Oyeku.jade(0);
        }

        ti (Ika.gigun(input) == 0) { tesiwaju; }

        ayanmo parts = Ika.ge(input, 0, Ika.gigun(input));
        // simplified: match first word
        ayanmo cmd = input;
        ti (cmd == "help") { show_help(); }
        bibẹkọ ti (cmd == "clear") { Irosu.mo(); }
        bibẹkọ { Irosu.kigbe("Unknown: " + cmd); }
    }
}

main();

    File Operations

    Save & Count Commands 
    ese save_file(path, content) {
    Odi.ko(path, content);
    Irosu.fo("Saved " + Ika.gigun(content) + " bytes to " + path);
}

ese count_file(path) {
    ti (Odi.wa(path)) {
        ayanmo content = Odi.ka(path);
        Irosu.fo("Lines: " + Ika.gigun(content));
    } bibẹkọ {
        Irosu.kigbe("File not found: " + path);
    }
}

save_file("note.txt", "Hello, Ifá-Lang!");
count_file("note.txt");

    Background Tasks

    Async with Osa 
    ese background_task(name, duration) {
    Irosu.fo("Task " + name + " started");
    Oyeku.sun(duration);
    Irosu.fo("Task " + name + " done");
}

ese run_tasks() {
    // Spawn concurrent tasks
    Osa.sa({ -> background_task("A", 1000) });
    Osa.sa({ -> background_task("B", 500) });
    Osa.sa({ -> background_task("C", 2000) });
    Irosu.fo("All tasks spawned");
}

run_tasks();
