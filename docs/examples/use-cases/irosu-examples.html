Irosu Domain Examples

Console I/O and User Interaction (1100)

Overview

Irosu (1100) provides console input/output operations including printing, reading input, clearing the screen, and error output.

Domain Characteristics

  • Binary Pattern: 1100 (communication and clarity)
  • Yoruba Meaning: "The watcher" or "The observer"
  • System Role: Console I/O
  • Element: Air

Available Methods

  • fo | println — print with newline
  • so | print — print without newline
  • gbo | listen — read console input
  • gbo_nomba — read number from console
  • mo | clear — clear screen
  • san | flush — flush output
  • kigbe | error — print error

Basic Console Operations

Text Output

Printing 
// Print with newline
Irosu.fo("Hello, Ifá-Lang!");

// Print without newline
Irosu.so("Entering data...");
Irosu.so(" done");

// Error output
Irosu.kigbe("Something went wrong");

// Flush output buffer
Irosu.san();

User Input

Reading Input 
// Read string input
ayanmo name = Irosu.gbo("Enter your name: ");
Irosu.fo("Hello, " + name + "!");

// Read number input
ayanmo age = Irosu.gbo_nomba("Enter your age: ");
Irosu.fo("You are " + age + " years old");

Interactive Applications

Simple Greeting App

Name Repeat 
// Greeting loop
Irosu.fo("Enter your name (or 'quit' to exit):");

nigba (otito) {
    ayanmo name = Irosu.gbo("> ");
    ti (name == "quit" || name == "jade") {
        Irosu.fo("Goodbye!");
        Oyeku.jade(0);
    }
    Irosu.fo("Hello, " + name + "!");
    Oyeku.sun(500);
}

Calculator Example

Number Input 
// Simple calculator using gbo_nomba
Irosu.fo("Simple Calculator");

ayanmo a = Irosu.gbo_nomba("First number: ");
ayanmo b = Irosu.gbo_nomba("Second number: ");

ayanmo sum = Obara.fikun(a, b);
ayanmo product = Obara.isodipupo(a, b);

Irosu.fo("Sum: " + sum);
Irosu.fo("Product: " + product);

Screen Control

Clear Screen 
// Clear screen and show message
Irosu.mo();
Irosu.fo("Screen cleared!");
Irosu.fo("Press Enter to exit...");
Irosu.gbo("");
