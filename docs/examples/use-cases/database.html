    File-Based Record Management with Ifá-Lang

    Overview

    Ifá-Lang does not yet have a dedicated database domain. This example uses Odi file I/O for persistent record storage — a common pattern until native database support lands. Records are stored as newline-delimited JSON-like entries in a flat file, with Ogunda for list operations and Ika for string processing.

    Domains Used

    • Odi - Read/write record file, check existence
    • Ogunda - List append, filter, length
    • Ika - String concat, slice, length
    • Irosu - Console I/O

    File-Backed Record Store 
    // Simple file-backed record store
ese insert(db_path, record) {
    ayanmo line = Irete.base64_encode(Irete.sha256(record)) + "|" + record;
    ayanmo existing = "";
    ti (Odi.wa(db_path)) {
        existing = Odi.ka(db_path);
    }
    Odi.ko(db_path, existing + line + "\n");
}

ese list_all(db_path) -> Vec {
    ti (Odi.wa(db_path)) {
        ayanmo content = Odi.ka(db_path);
        pada Ika.ge(content, 0, Ika.gigun(content));
        // In practice, split lines and return records
    }
    pada [];
}

ese count(db_path) {
    ayanmo records = list_all(db_path);
    Irosu.fo("Total records: " + Ogunda.iwọn(records));
}

// Usage
insert("users.db", "alice,alice@example.com");
insert("users.db", "bob,bob@example.com");
count("users.db");
