    REST API Client

    HTTP API Client with Ifá-Lang's Otura Domain

    Overview

    This example demonstrates building an HTTP API client using Otura.gba (GET/fetch) and Otura.ran (POST) for REST API communication. Data is persisted locally with Odi file I/O. Response processing uses Ika string helpers.

    Domains Used

    • Otura - HTTP GET (gba) and POST (ran) — requires `backend` feature
    • Odi - File read/write for caching and config
    • Ika - String processing for URL/header construction
    • Irosu - Console logging

    HTTP GET Request

    Fetch Data from API

}

    Full Workflow

    Integrated API Client 
    ese sync_data() {
    // 1. Fetch remote data
    ayanmo data = Otura.gba("https://api.example.com/data");

    // 2. Cache locally
    Odi.ko("data/snapshot.json", data);

    // 3. Log
    Irosu.fo("Sync complete: " + Ika.gigun(data) + " bytes");

    // 4. Check for update
    ayanmo key = load_api_key();
    ti (Ika.gigun(key) > 0) {
        ayanmo result = Otura.ran("https://api.example.com/sync",
                                  "key=" + key);
        Irosu.fo("Push result: " + result);
    }
}
