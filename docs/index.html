16 Odù Domains

Every aspect of programming maps to an Odù — sacred patterns of Ifá divination.

1111 Ogbe

System — Process control, environment variables, command-line args

0000 Òyèkú

Exit — Process termination, exit codes, sleep, halt

0110 Ìwòrì

Time — Timestamps, durations, scheduling, loops

1001 Òdí

File — File read/write/append, path management, database

1100 Ìròsú

Log — Print, read, colored output, terminal control

0011 Ọ̀wọ́nrín

Random — Random number generation, shuffle, choice, UUID

1000 Ọ̀bàrà

Math — Arithmetic, add/mul, pow, sqrt, trig

0001 Ọ̀kànràn

Error — Assertions, throw, panic, error handling

1110 Ògúndá

Array — List/array ops, push/pop, map, filter, sort

0111 Ọ̀sá

Flow — Concurrency, async tasks, channels, spawn

0100 Ìká

String — String manipulation, concat, case, split/join

0010 Òtúúrúpọ̀n

Reduce — Subtraction, division, modulo, negation

1011 Òtúrá

Net — HTTP GET/POST, TCP/UDP, sockets

1101 Ìrẹtẹ̀

Crypto — SHA-256, HMAC, base64, compression

1010 Ọ̀ṣẹ́

UI — Terminal UI, drawing, color, key input

0101 Òfún

Root — Permissions, type reflection, capability checks, debug

Crypto Example

crypto.ifa 
// Hash a message with Irete (Crypto)
ayanmo ifiranṣẹ = "Ifá is wisdom";
ayanmo hash = Irete.sha256(ifiranṣẹ);
Irosu.fo("SHA256: " + hash);

// Generate a UUID
ayanmo id = Irete.uuid();
Irosu.fo("UUID: " + id);
// Hash a message with Irete (Crypto)
let message = "Ifá is wisdom";
let hash = Irete.sha256(message);
Irosu.println("SHA256: " + hash);

// Generate a UUID
