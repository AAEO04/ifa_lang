    1. CI Workflow (ci.yml)

    Runs on push to main/develop, on tags v*, and on PRs to main (ci.yml:3-8). Three job groups:

    1a. Opon Check (Cross-Platform)

    Matrix: ubuntu/x86_64, macos/arm64, windows/x86_64 (ci.yml:22-31). Steps:

    1. cargo fmt --all -- --check — formatting
    2. cargo clippy --workspace --all-targets -- -D warnings — linting (deny mode)
    3. cargo build --workspace — full workspace build
    4. cargo test --workspace — all tests
    5. cargo test -p ifa-embedded --test cross_runtime — embedded cross-runtime test

    1b. Specialized Build Verification

    1c. Benchmark Sanity

    cargo bench --no-run — verifies benchmarks compile without running them (ci.yml:93-102).

    2. Release Workflow (release.yml)

    Triggered by v* tag push. See Release Process for full details. Key properties:

    • fail-fast: false — all platforms build even if one fails
    • Two binaries per platform: ifa + ifa-installer-gui
    • GUI installer skipped on cross-compiled targets (ARM Linux)
    • Checksums generated with sha256sum
    • Changelog auto-generated via git log

    3. Docs Deployment

    update-docs-release-assets.yml handles documentation updates.

    Not yet covered by CI:

    • cargo test --doc (doc-tests) — not included in current configuration
    • Benchmark result tracking / performance regression detection
    • crates.io publishing (manual)
    • docs.rs metadata for most crates (only ifa-bytecode has all-features = true)
