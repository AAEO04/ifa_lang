    0010 Oturupon

    The Reducer — Subtraction & Division

    Source of truth note: Verified against crates/ifa-std/src/oturupon.rs.

    Subtraction

    din / sub

    Oturupon.din(a: Int, b: Int) → Int

    Checked integer subtraction. Returns overflow error if result overflows i64.

    din_f / sub_float

    Oturupon.din_f(a: Float, b: Float) → Float

    Float subtraction.

    Division

    pin / div

    Oturupon.pin(a: Int, b: Int) → Float

    Integer division returning float. Errors on division by zero.

    pin_odidi / div_int

    Oturupon.pin_odidi(a: Int, b: Int) → Int

    Integer division returning integer (truncated).

    pin_f / div_float

    Oturupon.pin_f(a: Float, b: Float, mode: RoundingMode) → Float

    Float division with rounding mode: Truncate, Floor, Ceiling, or HalfEven (banker's rounding).

    Oturupon.pin_f(7.0, 2.0, "Floor")  // 3.0

    Modulo

    ku / modulo

    Oturupon.ku(a: Int, b: Int) → Int

    Remainder (a % b).

    ku_euclidean / euclidean_mod

    Oturupon.ku_euclidean(a: Int, b: Int) → Int

    Euclidean modulo (always non-negative result).

    Other

    dake / negate

    Oturupon.dake(x: Int) → Int

    Checked negation. Errors on i64::MIN.

    idakeji / reciprocal

    Oturupon.idakeji(x: Float) → Float

    Reciprocal (1/x). Errors on zero.

    iyoku / remaining

    Oturupon.iyoku(value: Int, max: Int) → Int

    Difference from max (max - value).
