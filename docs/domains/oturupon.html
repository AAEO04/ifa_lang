    0010 Oturupon

    The Reducer — Subtraction & Division

    Source of truth note: Verified against crates/ifa-types/src/odu_metadata.rs.

    Subtraction

    yokuro / sub / minus

    Oturupon.yokuro(a: Int, b: Int) → Int

    Checked integer subtraction.

    Division

    pipin / div / divide

    Oturupon.pipin(a: Int, b: Int) → Float

    Integer division returning float. Errors on division by zero.

    Checked Arithmetic

    din / sub_checked

    Oturupon.din(a: Int, b: Int) → Int

    Checked integer subtraction. Panics on overflow.

    pin / div_checked

    Oturupon.pin(a: Int, b: Int) → Int

    Checked integer division. Panics on zero or overflow.

    pin_odidi / div_int

    Oturupon.pin_odidi(a: Int, b: Int) → Int

    Integer division (truncated).

    Float Arithmetic

    din_f / sub_float

    Oturupon.din_f(a: Float, b: Float) → Float

    Float subtraction.

    pin_f / div_float

    Oturupon.pin_f(a: Float, b: Float) → Float

    Float division.

    Remainder & Negation

    ku / rem_checked

    Oturupon.ku(a: Int, b: Int) → Int

    Checked integer remainder.

    ku_euclidean / rem_euclidean

    Oturupon.ku_euclidean(a: Int, b: Int) → Int

    Euclidean remainder (always non-negative).

    dake / neg_checked

    Oturupon.dake(a: Int) → Int

    Checked integer negation.

    idakeji / reciprocal

    Oturupon.idakeji(a: Int) → Float

    Reciprocal (1/x).

    iyoku / diff

    Oturupon.iyoku(a: Int, b: Int) → Int

    Absolute difference between two integers.

    Example

    ayanmo result = Oturupon.yokuro(10, 3);  // 7
ayanmo quotient = Oturupon.pipin(10, 3);  // 3.333
    let result = Oturupon.sub(10, 3);  // 7
let quotient = Oturupon.div(10, 3);  // 3.333
