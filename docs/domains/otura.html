    1011 Otura

    The Messenger — Networking (HTTP/TCP)

    Source of truth note: Verified against crates/ifa-std/src/otura.rs. Features SSRF protection (blocks localhost, private IPs, cloud metadata endpoints). Requires full feature for networking; Network capability for host access.

    Security

    sayewo / check_host

    Otura.sayewo(host: Str) → Bool

    Check if a host is allowed through SSRF protection + capability gate.

    HTTP (full feature)

    gba / http_get

    Otura.gba(url: Str) → Str

    HTTP GET request. Returns response body as string.

    ayanmo body = Otura.gba("https://api.example.com/data");

    Otura.ran(url: Str, body: Str) → Str

    HTTP POST request with body. Returns response body.

    TCP (full feature)

    de / tcp_listen

    Otura.de(addr: Str) → TcpListener

    Bind TCP listener to address. Requires wildcard Network capability.

    soro / tcp_connect

    Otura.soro(addr: Str) → TcpStream

    Connect to TCP address. SSRF protected.

    SSRF Protection

    The following hosts/ranges are always blocked:

    • localhost, 127.0.0.1, ::1
    • 0.0.0.0
    • 169.254.169.254 (cloud metadata)
    • metadata.google.internal
    • All private IPv4 ranges (10.x, 172.16-31.x, 192.168.x)
    • Link-local addresses
