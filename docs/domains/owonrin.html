    0011 Owonrin

    The Shuffler — Random Number Generation

    Source of truth note: Verified against crates/ifa-std/src/odu/owonrin.rs. Uses ChaCha20 CSPRNG. Requires Random capability.

    Random Numbers

    pese / random_int

    Owonrin.pese(min: Int, max: Int) → Int

    Random integer in inclusive range min..=max.

    ayanmo roll = Owonrin.pese(1, 6);  // Dice roll
    let roll = Owonrin.random_int(1, 6);  // Dice roll

    pese_odidi / random_float

    Owonrin.pese_odidi() → Float

    Random float in 0.0..1.0.

    ayanmo pct = Owonrin.pese_odidi();
    let pct = Owonrin.random_float();

    pese_larin / random_range

    Owonrin.pese_larin(min: Float, max: Float) → Float

    Random float in range min..max.

    ayanmo temp = Owonrin.pese_larin(36.0, 40.0);
    let temp = Owonrin.random_range(36.0, 40.0);

    boya / random_bool

    Owonrin.boya(probability: Float) → Bool

    Random boolean with given probability (0.0-1.0) of being true.

    ti (Owonrin.boya(0.5)) { Irosu.fo("Heads!"); }
    if (Owonrin.random_bool(0.5)) { Irosu.println("Heads!"); }

    Selection & Shuffling

    yan / choose

    Owonrin.yan(items: List) → Any?

    Random choice from a list. Returns null if empty.

    ayanmo color = Owonrin.yan(["red", "green", "blue"]);
    let color = Owonrin.choose(["red", "green", "blue"]);

    paaro / shuffle

    Owonrin.paaro(items: List)

    Shuffle list in place.

    Owonrin.paaro(deck);
    Owonrin.shuffle(deck);

    yan_iwuwo / weighted_choice

    Owonrin.yan_iwuwo(items: List(Tuple(Any, Float))) → Any?

    Weighted random choice from (item, weight) pairs.

    ayanmo pick = Owonrin.yan_iwuwo([
    ("common", 0.8),
    ("rare", 0.15),
    ("legendary", 0.05)
]);
    let pick = Owonrin.weighted_choice([
    ("common", 0.8),
    ("rare", 0.15),
    ("legendary", 0.05)
]);

    Byte Generation

    awon_bytes / random_bytes

    Owonrin.awon_bytes(count: Int) → List(Byte)

    Generate random bytes.

    ayanmo key = Owonrin.awon_bytes(32);
    let key = Owonrin.random_bytes(32);

    hex / hex_string

    Owonrin.hex(bytes: Int) → Str

    Generate random hex string.

    ayanmo token = Owonrin.hex(16);  // 32-char hex
    let token = Owonrin.hex_string(16);  // 32-char hex

    uuid

    Owonrin.uuid() → Str

    Generate UUID v4 string.

    ayanmo id = Owonrin.uuid();  // "550e8400-..."
    let id = Owonrin.uuid();  // "550e8400-..."

    Seeding

    By default Owonrin uses entropy-seeded ChaCha20. A seeded instance can be created with from_seed(seed, capabilities) for reproducible sequences (available in Rust API).
