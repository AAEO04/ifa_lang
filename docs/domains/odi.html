    1001 Odi

    The Seal — File I/O

    Source of truth note: Verified against crates/ifa-types/src/odu_metadata.rs. All file operations are sandboxed via capability checks. Requires ReadFiles / WriteFiles capabilities.

    Read Operations

    ka / read

    Odi.ka(path: Str) → Str

    Read file contents as UTF-8 string.

    Write Operations

    ko / write

    Odi.ko(path: Str, content: Str)

    Write content to file (overwrites).

    File System

    wa / exists

    Odi.wa(path: Str) → Bool

    Check if file or directory exists.

    si / open

    Odi.si(path: Str) → Handle

    Open a file handle for reading.

    pa / close

    Odi.pa(handle: Handle)

    Close an open file handle.

    pa_iwe / delete

    Odi.pa_iwe(path: Str)

    Delete a file.

    so_po / append

    Odi.so_po(path: Str, content: Str)

    Append content to a file.

    pa_re / rename

    Odi.pa_re(old: Str, new: Str)

    Rename or move a file.

    is_file

    Odi.is_file(path: Str) → Bool

    Check if path is a file (not a directory).

    is_dir

    Odi.is_dir(path: Str) → Bool

    Check if path is a directory.

    Example

    ayanmo content = Odi.ka("hello.txt");
Irosu.fo(content);
Odi.ko("output.txt", "Ifá-Lang");
    let content = Odi.read("hello.txt");
Irosu.println(content);
Odi.write("output.txt", "Ifá-Lang");
