    1001 Odi

    The Seal — File I/O & SQLite Database

    Source of truth note: Verified against crates/ifa-std/src/odi.rs. All file operations are sandboxed via capability checks. Requires ReadFiles / WriteFiles capabilities.

    Read Operations

    ka / read

    Odi.ka(path: Str) → Str

    Read file contents as UTF-8 string.

    ka_bytes / read_bytes

    Odi.ka_bytes(path: Str) → List(Byte)

    Read file as raw bytes.

    ka_mmap / read_mmap

    Odi.ka_mmap(path: Str) → Str

    Memory-map file for zero-copy access.

    ka_ila / read_lines

    Odi.ka_ila(path: Str) → List(Str)

    Read file as lines.

    Write Operations

    ko / write

    Odi.ko(path: Str, content: Str)

    Write content to file (overwrites).

    fi / append

    Odi.fi(path: Str, content: Str)

    Append content to file.

    File System

    wa / exists

    Odi.wa(path: Str) → Bool

    Check if file or directory exists.

    pa_faili / remove / delete

    Odi.pa_faili(path: Str)

    Delete file.

    seda_apoti / mkdir

    Odi.seda_apoti(path: Str)

    Create directory (and parents).

    akojo / ls / list

    Odi.akojo(path: Str) → List(Str)

    List directory entries.

    iwon / size

    Odi.iwon(path: Str) → Int

    Get file size in bytes.

    SQLite Database

    so_db / open_db

    Odi.so_db(path: Str) → Connection

    Open SQLite database file (requires read + write capability).

    ayanmo db = Odi.so_db("/tmp/mydb.sqlite");

    so_db_iranti / open_memory_db

    Odi.so_db_iranti() → Connection

    Open in-memory SQLite database (no file perm needed).
