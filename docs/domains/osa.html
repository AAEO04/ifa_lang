    0111 Osa

    The Runner — Concurrency & Async

    Source of truth note: Verified against crates/ifa-std/src/osa.rs. Requires full feature (tokio-based). In minimal builds only a placeholder method is available.

    Task Management

    sa / spawn

    Osa.sa(future: Future) → JoinHandle

    Spawn an async task on the tokio runtime.

    ayanmo handle = Osa.sa(async {
    // Do work
    42
});
ayanmo result = handle.await;

    sun / sleep

    Osa.sun(ms: Int)

    Async sleep for milliseconds (non-blocking).

    jeki / yield

    Osa.jeki()

    Yield control to the tokio scheduler.

    Channels

    oju_ona / channel

    Osa.oju_ona(buffer: Int) → (Sender, Receiver)

    Create a multi-producer, multi-consumer channel.

    oju_ona_kan / oneshot

    Osa.oju_ona_kan() → (Sender, Receiver)

    Create a one-shot channel (single value).

    Synchronization

    titipe / mutex

    Osa.titipe(value: Any) → Mutex

    Create an async-compatible mutex.

    kaka / rwlock

    Osa.kaka(value: Any) → RwLock

    Create an async-compatible read-write lock.

    Utilities

    pelu_akoko / with_timeout

    Osa.pelu_akoko(future: Future, timeout_ms: Int) → Any?

    Run a future with timeout; returns null if timed out.
