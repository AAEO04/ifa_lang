    0101 Ofun

    The Reflector — Permissions & Reflection

    Source of truth note: Verified against crates/ifa-std/src/ofun.rs.

    Permission Checking

    le / can

    Ofun.le(cap: Str) → Bool

    Check if a capability is granted. Supported capabilities:

    Ofun.le("read");          // Can read files
Ofun.le("write");         // Can write files
Ofun.le("network");       // Can access network
Ofun.le("spawn");         // Can spawn processes
Ofun.le("env");           // Can access environment
Ofun.le("bridge:python"); // Can bridge to Python

    ju / drop

    Ofun.ju(cap: Str)

    Drop (revoke) a capability. Can only remove, never add.

    Ofun.ju("write");  // Revoke write permission

    awon_agbara / get_capabilities

    Ofun.awon_agbara() → Capabilities

    Get current capabilities struct.

    Reflection

    iru / type_of

    Ofun.iru(value: Any) → Str

    Get type name of a value: Null, Bool, Int, Float, Str, List, Map, Function, Resource.

    je / is

    Ofun.je(value: Any, type_name: Str) → Bool

    Check if value is of specified type.

    afiwe / debug

    Ofun.afiwe(value: Any) → Str

    Get debug string representation of value.

    Capability Presets

    read_only() — read + env only, no write/network/spawn

    none() — all capabilities revoked (fully sandboxed)

    full() — all capabilities including all bridge languages
