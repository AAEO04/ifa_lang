System Domain — CLI Arguments & Environment

Source of truth note: Verified against crates/ifa-std/src/odu/ogbe.rs.

CLI Arguments

awon_ohun / args

Ogbe.awon_ohun() → List(Str)

Get all CLI arguments as a list of strings.

ohun / arg

Ogbe.ohun(index: Int) → Str?

Get CLI argument at index. Returns null if index out of range.

iye_ohun / arg_count

Ogbe.iye_ohun() → Int

Get number of CLI arguments.

Environment Variables

ayika / get_env

Ogbe.ayika(key: Str) → Str?

Get environment variable. Returns null if not set or capability denied.

ayika_tabi / get_env_or

Ogbe.ayika_tabi(key: Str, default: Str) → Str

Get environment variable with default fallback.

fi_ayika / set_env (deprecated)

Ogbe.fi_ayika(key: Str, value: Str)

Deprecated since 1.2.1. Setting environment variables at runtime is thread-unsafe. This operation is a no-op that prints a warning.

System Information

ile / home_dir

Ogbe.ile() → Str?

Get home directory path ($HOME or $USERPROFILE).

oju_ona / cwd

Ogbe.oju_ona() → Str?

Get current working directory.

eto / os

Ogbe.eto() → Str

Get operating system name (e.g. linux, windows, macos).

apere / arch

Ogbe.apere() → Str

Get CPU architecture (e.g. x86_64, aarch64).

Example

ese main() {
    ayanmo args = Ogbe.awon_ohun();
    ayanmo count = Ogbe.iye_ohun();

    ti (count < 2) {
        Irosu.fo("Usage: " + Ogbe.ohun(0) + " ");
        Oyeku.ku(1);
    }

    ayanmo filename = Ogbe.ohun(1);
    Irosu.fo("Running on: " + Ogbe.eto() + " (" + Ogbe.apere() + ")");
    Irosu.fo("Working directory: " + Ogbe.oju_ona());
}
