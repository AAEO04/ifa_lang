    0100 Ika

    The Controller — Strings & Serialization

    Source of truth note: Verified against crates/ifa-std/src/ika.rs.

    String Operations

    so / concat

    Ika.so(parts: List(Str)) → Str

    Concatenate strings.

    Ika.so(["Hello", " ", "World"])  // "Hello World"

    gigun / len

    Ika.gigun(s: Str) → Int

    String length in characters (not bytes).

    nla / uppercase

    Ika.nla(s: Str) → Str

    Convert to uppercase.

    kekere / lowercase

    Ika.kekere(s: Str) → Str

    Convert to lowercase.

    wa / find

    Ika.wa(haystack: Str, needle: Str) → Int?

    Find position of substring.

    ni / has

    Ika.ni(haystack: Str, needle: Str) → Bool

    Check if string contains substring.

    pin / split

    Ika.pin(s: Str, delimiter: Str) → List(Str)

    Split string by delimiter.

    dapo / join

    Ika.dapo(parts: List(Str), separator: Str) → Str

    Join strings with separator.

    yi_pada / replace

    Ika.yi_pada(s: Str, from: Str, to: Str) → Str

    Replace all occurrences.

    ge / trim

    Ika.ge(s: Str) → Str

    Trim whitespace from both ends.

    pada / reverse

    Ika.pada(s: Str) → Str

    Reverse string by characters.

    ge_lara / substring

    Ika.ge_lara(s: Str, start: Int, end: Int) → Str

    Extract substring by character indices.

    tun / repeat

    Ika.tun(s: Str, n: Int) → Str

    Repeat string n times.

    bere / starts_with

    Ika.bere(s: Str, prefix: Str) → Bool

    Check if string starts with prefix.

    pari / ends_with

    Ika.pari(s: Str, suffix: Str) → Bool

    Check if string ends with suffix.

    Regex

    ba_mu / regex_match

    Ika.ba_mu(pattern: Str, text: Str) → Bool

    Check if regex matches text.

    wa_akoko / regex_find

    Ika.wa_akoko(pattern: Str, text: Str) → Str?

    Find first regex match.

    wa_gbogbo / regex_find_all

    Ika.wa_gbogbo(pattern: Str, text: Str) → List(Str)

    Find all regex matches.

    ropo / regex_replace

    Ika.ropo(pattern: Str, text: Str, replacement: Str) → Str

    Replace all regex matches.

    Serialization

    yi_si_json / encode

    Ika.yi_si_json(value: Any) → Str

    Serialize value to JSON string.

    yi_pada_json / decode

    Ika.yi_pada_json(json: Str) → Any

    Deserialize JSON string to Ifá value.

    yi_si_csv / to_csv

    Ika.yi_si_csv(rows: List(List)) → Str

    Serialize matrix to CSV string.

    yi_pada_csv / from_csv

    Ika.yi_pada_csv(data: Str, has_headers: Bool) → List(List)

    Deserialize CSV to matrix.

    bo_asiri_url / url_encode

    Ika.bo_asiri_url(text: Str) → Str

    URL-encode a string.

    titu_asiri_url / url_decode

    Ika.titu_asiri_url(text: Str) → Str

    URL-decode a string.

    Rope Operations (Large Text)

    rope_new

    Ika.rope_new(s: Str) → Rope

    Create a rope from string for efficient large-text editing.

    rope_insert

    Ika.rope_insert(rope: Rope, idx: Int, text: Str)

    rope_delete

    Ika.rope_delete(rope: Rope, start: Int, end: Int)

    rope_slice

    Ika.rope_slice(rope: Rope, start: Int, end: Int) → Str

    rope_len

    Ika.rope_len(rope: Rope) → Int

    HTML Operations (html feature)

    The following methods are available behind the html feature flag:

    mo / clean_html

    Ika.mo(html: Str) → Str

    Strip HTML tags and return plain text.

    wa_html / query

    Ika.wa_html(html: Str, selector: Str) → List(Str)

    Query selector — returns text content of matching nodes.

    oruko_html / title

    Ika.oruko_html(html: Str) → Str

    Get title of HTML document.
