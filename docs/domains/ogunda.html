    1110 Ogunda

    The Warrior — Arrays & Collections

    Source of truth note: Verified against crates/ifa-types/src/odu_metadata.rs.

    Array Operations

    iwon / len / count / apapo

    Ogunda.iwon(list: List) → Int

    Get list length.

    fi / push / append

    Ogunda.fi(list: List, item: Any)

    Push item to end of list.

    mu / pop

    Ogunda.mu(list: List) → Any?

    Pop item from end of list.

    yi_pada / map / maapu

    Ogunda.yi_pada(list: List, mapper: Function) → List

    Map function over list.

    yan / filter

    Ogunda.yan(list: List, predicate: Function) → List

    Filter list with predicate function.

    ṣẹ́kù / reduce / fold

    Ogunda.ṣẹ́kù(list: List, fn: Function, init: Any) → Any

    Reduce list with accumulator function.

    ge / alloc

    Ogunda.ge(size: Int) → List

    Allocate a list with given size.

    da / create

    Ogunda.da() → List

    Create a new empty list.

    Creation & Inspection

    seda / new_list

    Ogunda.seda(items: List) → List

    Create a new list from existing items.

    seda_agbara / with_capacity

    Ogunda.seda_agbara(capacity: Int) → List

    Create a new list with pre-allocated capacity.

    sofo / is_empty

    Ogunda.sofo(list: List) → Bool

    Check if list is empty.

    pada / reverse

    Ogunda.pada(list: List) → List

    Reverse list order.

    to / sort

    Ogunda.to(list: List) → List

    Sort list in ascending order.

    dapo / concat

    Ogunda.dapo(list_a: List, list_b: List) → List

    Concatenate two lists.

    wa / find

    Ogunda.wa(list: List, fn: Function) → Any

    Find first element matching predicate.

    eyikeyi / any

    Ogunda.eyikeyi(list: List, fn: Function) → Bool

    Check if any element matches predicate.

    gbogbo / all

    Ogunda.gbogbo(list: List, fn: Function) → Bool

    Check if all elements match predicate.

    Map Operations

    awon_kokoro / keys

    Ogunda.awon_kokoro(map: Map) → List

    Get all keys from a map.

    awon_iye / values

    Ogunda.awon_iye(map: Map) → List

    Get all values from a map.

    awon_nkan / items

    Ogunda.awon_nkan(map: Map) → List

    Get all [key, value] pairs from a map.

    yo / remove

    Ogunda.yo(map: Map, key: Any) → Map

    Remove a key from a map.

    Process & Environment

    sise / run

    Ogunda.sise(cmd: Str, args: List) → Int

    Run a command and return exit code.

    sise_ka / run_read

    Ogunda.sise_ka(cmd: Str, args: List) → Str

    Run a command and capture stdout.

    bere / spawn

    Ogunda.bere(cmd: Str, args: List) → Pid

    Spawn a background process.

    ayika / get_env

    Ogunda.ayika(key: Str) → Str?

    Get environment variable value.

    Example

    ayanmo items = [1, 2, 3];
ayanmo doubled = Ogunda.yi_pada(items, ese(x) { x * 2 });  // [2, 4, 6]
    let items = [1, 2, 3];
let doubled = Ogunda.map(items, fn(x) { x * 2 });  // [2, 4, 6]
