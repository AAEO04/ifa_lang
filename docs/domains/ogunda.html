ogunda.ifa

    1110 Ogunda

    The Warrior — Arrays & Process Management

    Source of truth note: Verified against crates/ifa-std/src/ogunda.rs. Subprocess commands are sandboxed with shell-injection protection.

    Array Operations

    seda / new

    Ogunda.seda() → List

    Create new empty list.

    seda_agbara / with_capacity

    Ogunda.seda_agbara(capacity: Int) → List

    Create list with pre-allocated capacity.

    fi / push

    Ogunda.fi(list: List, item: Any)

    Push item to end of list.

    mu / pop

    Ogunda.mu(list: List) → Any?

    Pop item from end of list.

    iwon / len

    Ogunda.iwon(list: List) → Int

    Get list length.

    sofo / is_empty

    Ogunda.sofo(list: List) → Bool

    Check if list is empty.

    pada / reverse

    Ogunda.pada(list: List) → List

    Return reversed copy of list.

    to / sort

    Ogunda.to(list: List) → List

    Return sorted copy of list.

    dapo / concat

    Ogunda.dapo(a: List, b: List) → List

    Concatenate two lists.

    yan / filter

    Ogunda.yan(list: List, predicate: Function) → List

    Filter list with predicate function.

    yi_pada / map

    Ogunda.yi_pada(list: List, mapper: Function) → List

    Map function over list.

    wa / find

    Ogunda.wa(list: List, predicate: Function) → Any?

    Find first matching element.

    eyikeyi / any

    Ogunda.eyikeyi(list: List, predicate: Function) → Bool

    Check if any element matches predicate.

    gbogbo / all

    Ogunda.gbogbo(list: List, predicate: Function) → Bool

    Check if all elements match predicate.

    ge / slice

    Ogunda.ge(list: List, start: Int, end: Int) → List

    Slice list from start (inclusive) to end (exclusive).

    Map Operations

    awon_kokoro / keys

    Ogunda.awon_kokoro(map: Map) → List(Str)

    Get map keys as string list.

    awon_iye / values

    Ogunda.awon_iye(map: Map) → List

    Get map values as list.

    awon_nkan / items

    Ogunda.awon_nkan(map: Map) → List(List)

    Get map items as list of [key, value] pairs.

    yo / remove

    Ogunda.yo(map: Map, key: Str) → Any?

    Remove key from map and return its value.

    Process Operations

    sise / run

    Ogunda.sise(command: Str, args: List(Str)) → Output

    Run command and capture output. Shell interpreters are blocked for security.

    sise_ka / run_read

    Ogunda.sise_ka(command: Str, args: List(Str)) → Str

    Run command and capture stdout as string.

    bere / spawn

    Ogunda.bere(command: Str, args: List(Str)) → Int

    Spawn detached process, return PID.
