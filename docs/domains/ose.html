ose.ifa

    1010 Ose

    The Painter — Terminal UI (ratatui)

    Source of truth note: Verified against crates/ifa-std/src/ose.rs. Requires full feature (ratatui + crossterm). In minimal mode, all methods return a "TUI not compiled" error.

    Methods

    bere / init

    Ose.bere() → Resource

    Initialize terminal UI. Enables raw mode and switches to alternate screen. Returns a terminal resource token.

    ayanmo tty = Ose.bere();

    pari / end

    Ose.pari(tty: Resource)

    Restore terminal: disable raw mode, leave alternate screen, show cursor. Frees the terminal resource.

    ya / draw

    Ose.ya(tty: Resource, ui_map: Map)

    Draw UI from a declarative map. Supports widget types:

    Ose.ya(tty, {
    "type": "apoti",       // Box with border
    "title": "Header",
    "text": "Content"
});

Ose.ya(tty, {
    "type": "ipinro",      // Plain text
    "text": "Hello"
});

    gboran / listen

    Ose.gboran() → Str?

    Poll for key press (non-blocking). Returns key as string or null.

    ayanmo key = Ose.gboran();

    gbile / read_key

    Ose.gbile() → Str

    Blocking key read. Waits for a key press and returns it as string.

    ayanmo choice = Ose.gbile();

    Supported Keys

    • Character keys → the character as string
    • Enter, Esc, Up, Down, Left, Right, Backspace
