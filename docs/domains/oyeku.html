    0000 Oyeku

    The Sleeper — Exit & Sleep Operations

    Source of truth note: Verified against crates/ifa-std/src/odu/oyeku.rs. Sleep methods require Time capability.

    Exit

    ku / exit

    Oyeku.ku(code: Int) → !

    Exit the program with the given exit code.

    Oyeku.ku(0);   // Success
Oyeku.ku(1);   // Error

    ku_daadaa / exit_ok

    Oyeku.ku_daadaa() → !

    Exit successfully with code 0.

    Oyeku.ku_daadaa();

    ku_buruku / exit_err

    Oyeku.ku_buruku() → !

    Exit with error code 1.

    Oyeku.ku_buruku();

    da_duro / abort

    Oyeku.da_duro() → !

    Abort immediately with no cleanup. Use only in unrecoverable situations.

    Oyeku.da_duro();

    Sleep

    sun_ms / sleep_ms

    Oyeku.sun_ms(ms: Int)

    Sleep for the given number of milliseconds (requires Time capability).

    Oyeku.sun_ms(1000);  // Wait 1 second

    sun / sleep

    Oyeku.sun(seconds: Float)

    Sleep for the given number of seconds (requires Time capability).

    Oyeku.sun(1.5);  // Wait 1.5 seconds

    duro / wait

    Oyeku.duro(ms: Int)

    Alias for sun_ms. Sleep for milliseconds.

    Oyeku.duro(500);
