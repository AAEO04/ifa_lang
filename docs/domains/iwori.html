    0110 Iwori

    The Viewer — Time & Iteration

    Source of truth note: Verified against crates/ifa-std/src/odu/iwori.rs. Uses chrono for date/time.

    Current Time

    isisinyi / now

    Iwori.isisinyi() → DateTime

    Get current local time.

    utc

    Iwori.utc() → DateTime

    Get current UTC time.

    akoko / timestamp

    Iwori.akoko() → Int

    Unix timestamp in seconds.

    ayanmo now = Iwori.akoko();  // 1748044800

    akoko_ms / timestamp_ms

    Iwori.akoko_ms() → Int

    Unix timestamp in milliseconds.

    Date/Time Components

    odun / year

    Iwori.odun() → Int

    Current year.

    osu / month

    Iwori.osu() → Int

    Current month (1-12).

    ojo_osu / day

    Iwori.ojo_osu() → Int

    Current day of month (1-31).

    wakati / hour

    Iwori.wakati() → Int

    Current hour (0-23).

    iseju / minute

    Iwori.iseju() → Int

    Current minute (0-59).

    aaya / second

    Iwori.aaya() → Int

    Current second (0-59).

    ojo_ose / weekday

    Iwori.ojo_ose() → Int

    Day of week (0=Sunday, 6=Saturday).

    Formatting & Parsing

    ojo / format

    Iwori.ojo(format: Str) → Str

    Format current time using chrono format string.

    Iwori.ojo("%Y-%m-%d");  // "2026-05-24"

    ka_ojo / parse_date

    Iwori.ka_ojo(date_str: Str, format: Str) → DateTime?

    Parse date string. Returns null on failure.

    odun_abule / is_leap_year

    Iwori.odun_abule(year: Int) → Bool

    Check if year is a leap year.

    Calculations

    fikun / add_duration

    Iwori.fikun(days: Int, hours: Int, minutes: Int, seconds: Int) → DateTime

    Add duration to current time.

    Iwori.fikun(1, 0, 0, 0);  // Tomorrow

    iye_ojo / days_between

    Iwori.iye_ojo(from: DateTime, to: DateTime) → Int

    Number of days between two dates.

    Irosu.fo(i);  // 0, 1, 2, 3, 4, 5

    range_step(start: Int, end: Int, step: Int) → Iterator

    Irosu.fo(i);  // 0, 2, 4, 6, 8, 10
