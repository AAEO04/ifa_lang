irosu.ifa

1100 Irosu

Console Domain — Input/Output & Terminal Control

Source of truth note: Verified against crates/ifa-std/src/odu/irosu.rs. Requires Stdio capability.

Output

fo / println

Irosu.fo(value: Any)

Print value with newline.

Irosu.fo("Hello, Ifa!");

so / print

Irosu.so(value: Any)

Print value without newline.

Irosu.so("Enter name: ");

kigbe / error

Irosu.kigbe(text: Str)

Print to stderr with [ERROR] prefix.

Irosu.kigbe("Something went wrong");

awo / colored_print

Irosu.awo(text: Str, color: Str)

Print with color (requires crossterm feature). Colors: pupa/red, ewe/green, bulu/blue, ofeefe/yellow, funfun/white, arosayin/magenta, omi/cyan.

Irosu.awo("Success", "ewe");
Irosu.awo("Error", "pupa");

ilosiwaju / progress

Irosu.ilosiwaju(current: Int, total: Int, width: Int)

Display a progress bar.

Input

gbo / listen

Irosu.gbo(prompt: Str) → Str

Read line from stdin with optional prompt. Returns trimmed string.

ayanmo name = Irosu.gbo("Enter your name: ");

gbo_nomba / read_int

Irosu.gbo_nomba(prompt: Str) → Int

Read integer from stdin. Returns 0 on parse failure.

ayanmo age = Irosu.gbo_nomba("Age: ");

gbo_odidi / read_float

Irosu.gbo_odidi(prompt: Str) → Float

Read float from stdin. Returns 0.0 on parse failure.

Terminal Control

mo / clear

Irosu.mo()

Clear the terminal screen (requires crossterm feature).

san / flush

Irosu.san()

Flush stdout and stderr buffers.

Audio (feature: audio)

The following methods require the audio feature and use rodio for playback:

siro / play

Irosu.siro(path: Str) → AudioHandle

Play audio file. Returns an AudioHandle for control.

siro_duro / play_blocking

Irosu.siro_duro(path: Str)

Play audio file and block until playback finishes.

kigbe_orin / beep

Irosu.kigbe_orin()

Play a terminal bell beep.

Example

ese main() {
    ayanmo name = Irosu.gbo("Enter your name: ");
    Irosu.fo("Hello, " + name + "!");

    ti (name == "Ifa") {
        Irosu.awo("Welcome, wise one!", "ewe");
    } bibeko {
        Irosu.awo("Nice to meet you!", "bulu");
    }
}
