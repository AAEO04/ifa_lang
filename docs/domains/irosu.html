1100 Irosu

Console Domain — Input/Output & Terminal Control

Source of truth note: Verified against crates/ifa-types/src/odu_metadata.rs. Requires Stdio capability.

Output

fo / println

Irosu.fo(value: Any)

Print value with newline.

Irosu.fo("Hello, Ifa!");
Irosu.println("Hello, Ifa!");

so / print

Irosu.so(value: Any)

Print value without newline.

Irosu.so("Enter name: ");
Irosu.print("Enter name: ");

kigbe / error

Irosu.kigbe(text: Str)

Print to stderr with [ERROR] prefix.

Irosu.kigbe("Something went wrong");
Irosu.error("Something went wrong");

Input

gbo / listen

Irosu.gbo(prompt: Str) → Str

Read line from stdin with optional prompt. Returns trimmed string.

ayanmo name = Irosu.gbo("Enter your name: ");
let name = Irosu.listen("Enter your name: ");

gbo_nomba

Irosu.gbo_nomba(prompt: Str) → Int

Read integer from stdin. Returns 0 on parse failure.

ayanmo age = Irosu.gbo_nomba("Age: ");
let age = Irosu.read_int("Age: ");

ka / read / input

Irosu.ka(prompt: Str) → Str

Read line from stdin with optional prompt.

Terminal Control

mo / clear

Irosu.mo()

Clear the terminal screen.

san / flush

Irosu.san()

Flush stdout and stderr buffers.
